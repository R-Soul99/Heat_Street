## Shared Patterns

### Optional sidecar field, omitted when empty
**Source:** `src/core/terrain-format.ts` L553-555, L650, L686 (`unlockedEdgeIds`). **Apply to:** `startPoints`, `features`, building `style`. Must be touched in serializer, parser, AND `loadTerrainArea`.

### Strict allowlist input parsing
**Source:** `src/core/map-select.ts` L76-97. **Apply to:** `?start=`, `?heading=`, all sidecar variant ids (use Array `find`, never raw object key lookup).

### Undo as a StrokeDiff part, one stack
**Source:** `terrain-undo.ts` L94-97, `tool-dispatch.ts` L552-562. **Apply to:** every start-point, feature, building and ramp add/move/delete/rename/make-default. Do not assign `area.features = ...` outside the undo applier and the commit helper.

### Layering
**Source:** `tests/layering.test.ts` (globs `src/**/*.ts` only, `tools/` is exempt). `src/core`: no `three`, `@dimforge/rapier3d`, `document.`, `window.`, `performance.`, `requestAnimationFrame`. `src/physics`: no `three`. `src/render`: banned physics-mutation identifiers; no `innerHTML` anywhere under `src/`.

### DOM text and tips
**Source:** `buildSurfaceMenu` L1764-1803. **Apply to:** all new editor UI: `textContent` only (names from the sidecar can be hostile), `data-tip` on every control, `aria-label`, `role` attributes.

### Do not touch
`src/physics/vehicle.ts` (D-22), `public/maps/arena-test.terrain.*` (never stage or revert), `src/core/map-collision.ts`, crest ramp shapes (D-14).
