# Phase 07.1.3 Plan 09: Palette for point scenery and buildings Summary

The terrain editor now draws all features and buildings with the shared scenery view (style-less buildings as plain blocks) and lets the user place trees, bushes and buildings from a sidebar palette, with ghosts, refusals and the 40,000-triangle limit enforced.

## Commits
- 2625c63: scenery view in installArea/applyResult/undoRedo, reseat after sculpt, swatch palette sidebar, triangle readout and budget message line (Task 1)
- e0265ca: ghost, click placement, Scatter drag, building footprint drag, wheel rotation, routing and cancel paths (Task 2)

## What was built
- `createSceneryView(..., { drawStyleless: true })` installed per area; only the changed kind rebuilds on edit, undo and redo; features re-seat after sculpting under them (buildings re-seat in the stroke diff from plan 07).
- Palette sidebar for Building, Tree, Bush: `role="radiogroup"` swatches (3, 2 or 1 columns by the UI-SPEC rule via CSS grid `repeat(n, 1fr)`; buildings as a 1-column 40px row list), Scale, Random rotation (Rotation shown when Off), Scatter section closed by default with Density 1-20, Building Width/Depth/Height/Rotation. Values are remembered per kind for the session.
- "Scenery triangles: {t} / 40,000" readout (from `estimateSceneryTriangles`, game rule `drawStyleless: !legacyGlbBuildings`) plus an `aria-live="polite"` error-coloured message line. The limit decision is only in scenery-guards.
- Ghost follows the cursor (`buildFeaturePreview` for trees/bushes, translucent box for buildings, opacity 0.5); red tint, `not-allowed` cursor and info-bar reason on road paint or outside the area (building checks centre and four corners).
- Click places a tree/bush; Scatter drag paints seeded stamps through `fitScatterToBudget`, reports "Placed {n}, skipped {k}: scenery triangle limit (40,000)"; building footprint drag with accent outline and 0.25 fill, wheel turns 15 degrees only while dragging, dragged size writes back to Width/Depth. Each placement or drag is one undo step via `commitScenery`.
- Gestures refuse to start while `stroking || pushPull || opHold`, and cancel on Esc, pointercancel, pointerleave and `shell:dialog-open`; undo/redo is ignored while a scenery gesture is live.

## Deviations from Plan
1. Scatter working copy is displayed by pushing `[...features, ...work]` into the scenery view during the drag (real meshes, not 0.5-opacity ghosts), restored on cancel. Reason: `buildFeaturePreview` builds one feature per call.
2. No separate floating Radius chip exists in the shell; Radius is a stepper inside the Scatter section, shown only while Scatter is on (Square/Circle not offered, scatter is circular).
3. Added a MAX_BUILDINGS (2000) check before placing a building so the sidecar never exceeds the format limit.
4. `paintRingShapes` now returns early while a Place kind is armed (the ghost code owns the cursor ring), and `paintRing` calls `updatePlaceGhost` in that state.
5. Two commits as planned; Task 1 commit was made with Task 2 imports held back so each commit type-checks and lints clean.
