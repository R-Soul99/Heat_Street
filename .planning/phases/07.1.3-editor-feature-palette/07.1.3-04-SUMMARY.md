# Phase 07.1.3 Plan 04: Start-point tool wiring Summary

The terrain editor now arms Place > Start point (key 1), places start points by press-drag, shows pole/flag/arrow markers, manages them in a sidebar list (rename, make default, go to, delete; one undo step each), and drives from a start point or from the cursor/view centre.

## Deviations from Plan
1. Tasks 1 and 2 are one commit: pointer routing, sidebar list and drive code are interleaved in editor.ts and hunks cannot be split non-interactively.
2. D triggers Drive from; Drive here gets Shift+D (keyboard path uses the cursor point captured at keydown) plus a File menu entry.
3. The shell's menu labels are static, so the File entry reads "Drive from start point"; the "Drive from: {name}" label is on the sidebar button.
4. Marker picking uses a 2 m ground-distance test against the terrain hit instead of a Raycaster against meshes (same 2 m radius).
5. `lastHit` is cleared on canvas pointerleave so Drive here never uses a stale cursor.
