# Phase 07.1.3 Plan 07: Scenery operations, guards and undo Summary

Every scenery edit and refusal (road paint, area extent, 40,000-triangle budget) is a tested pure function, all scenery edits are one undo step through `commitScenery`, and styled buildings rise and fall with sculpting inside the stroke's own undo step.

## Key behaviours
- Refusal strings are exported constants (`ON_ROAD_REASON`, `OUTSIDE_AREA_REASON`, `BUDGET_REASON`, `NOTHING_SELECTED`, `BUILDING_TOO_SMALL`, ...) so plans 09-11 show identical copy.
- Budget: 70 oaks on the dense fixture (37,900) lands exactly on 40,000; the 71st is refused; deletes and moves are never refused, even over budget.
- Scatter: seeded LCG, `fitScatterToBudget` keeps what fits (70 of 100 with 2,100 headroom) and reports skipped.
- Ramp ids are `ramp-<n>` above the largest numeric ramp id and never equal to any crest id; the result round-trips through `parseTerrainSidecar`.
- Re-seat: the BEFORE heights come from a grid copy with the diff's before values written back (the live grid is already sculpted), made only when a styled building touches the stroke window. Undo restores the stored box exactly.

## Deviations from Plan
- (Rule 2) Re-seat is applied at all height-diff commit sites (selection raise/lower/smooth hold, push/pull, flatten, brush strokes, lock re-grade via `commitSceneryDiff`), not only brush strokes, so a building never floats after any terrain edit.
- Extra exports beyond the plan list for the later editor plans: `moveFeature`, `rotateFeature`, `scaleFeature`, `deleteFeature`, `deleteRamp`, `deleteBuilding`, `nextRampId`, `footprintCorners`, `insideArea`, `styledBuildingTouchesWindow`, `visibleHeightOf`.
- `ToolResult`/`UndoRedoResult` gained `featuresChanged`, `buildingsChanged`, `objectsChanged`.
