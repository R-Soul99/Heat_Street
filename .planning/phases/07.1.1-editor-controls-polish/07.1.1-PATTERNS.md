### `tool-groups.ts` + test (utility, transform)
**Analog:** `tools/editor-shell/dock.ts` lines 12-20, and `dock.test.ts` lines 1-20.

Pure, generic-typed, no DOM, order-preserving:
```typescript
export function splitDockTools<T extends { dock?: "top" }>(
  tools: readonly T[],
): { top: T[]; bottom: T[] } {
  const top: T[] = [];
  const bottom: T[] = [];
  for (const t of tools) (t.dock === "top" ? top : bottom).push(t);
  return { top, bottom };
}
```
Copy for `groupTools<T extends { group?: string }>(tools): { group: string | undefined; tools: T[] }[]` (consecutive runs). Test style (`dock.test.ts`):

Note stepper.test.ts imports without extension (`"./stepper"`), dock.test.ts with `.ts`; use `.ts`.

## Shared Patterns

### All DOM text via `textContent`, every interactive control has `data-tip`
**Source:** `tools/editor-shell/controls.ts` lines 4-17 (`el(tag, cls, text, tip)` sets `textContent` and `dataset.tip`). **Apply to:** all new buttons (value-box arrows, input, Raise/Lower pair, sidebar elements). Dividers get `role="separator"`, no `data-tip`. `auditTips` (tooltips.ts) warns on `button, input, select, summary` missing it. Never `innerHTML`, never `title=`.

### Pure logic split out and unit-tested
**Source:** `dock.ts`, `stepper.ts`, `tip-place.ts` + sibling `.test.ts` (vitest, `environment: "node"`, no DOM; `shell.ts`, `controls.ts`, `tool-rail.ts`, `tooltips.ts` cannot be imported in tests). **Apply to:** grouping, scrub maths, tip phase, wheel direction.

### Pointer-to-world uses the canvas rect
**Source:** terrain `pickTerrain` (editor.ts 829-833), map (1060-1061, 1205-1206): `canvas.getBoundingClientRect()`; `e.clientX - rect.left`. **Apply to:** anything new that reads pointer coordinates; never window/#app origin.

### Hotkey guard
**Source:** `tools/editor-shell/keys.ts` `isTextEntryFocused`. **Apply to:** value-box input; a scrub must blur the input so letter keys and `[ ]` keep working.
