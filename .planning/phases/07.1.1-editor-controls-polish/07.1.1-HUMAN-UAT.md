# Phase 07.1.1 Human UAT

Browser-only behaviours (layout, pointer, timing) that vitest in node cannot check.

## How to open

1. Run `npm run dev` (vite dev server; the editor API middleware is dev-only).
2. Terrain editor: `/tools/terrain-editor/index.html` on the dev server URL.
3. Map editor: `/tools/map-editor/index.html` on the dev server URL.

## D-01 Toolbar buttons: glyph + word + key letter

1. Open the terrain editor. Look at the bottom-left toolbar.
2. Expect every button to show a glyph, the full word (Paint, Road, Erase, Smooth box, Lock, Grid select...) and a small key letter top-right.
3. Repeat in the map editor.

[ ] pass / [ ] fail

## D-02 Grouped toolbar with dividers

1. Terrain toolbar groups: Smooth, Flatten | Grid select, Block, Smooth box | Paint | Road, Erase, Lock, Stamp, with thin dividers.
2. Map toolbar groups: Select, Move node | Draw road, Building | Eraser.
3. Narrow the window: wrapping happens between groups, never inside one.
4. Press each hotkey (terrain H J G F S B M P R E L W; map V M R B E): each selects the same tool as before.

[ ] pass / [ ] fail

## D-03 Tools stay in bottom-left

1. Confirm there is no top tool row in either editor; all tools live in the bottom-left toolbar.

[ ] pass / [ ] fail

## D-04 Raise/Lower on top of the terrain sidebar

1. Terrain sidebar top shows the up triangle over the down triangle.
2. Click each (and press H / J): it highlights and Raise/Lower options appear below.
3. Hover: tooltip names the tool and key.

[ ] pass / [ ] fail

## D-05 History buttons top-right

1. Undo / Redo / Clear all are still top-right and work in both editors.

[ ] pass / [ ] fail

## D-06 Fixed 240 px sidebar, stable canvas

1. Sidebar is always visible at 240 px; the canvas starts to its right and does not shift when switching tools.
2. On first load with no tool preselected, a "No tool selected" state shows.
3. In both editors, put the cursor near the sidebar edge, the centre and the right edge: the brush ring and edits land exactly under the cursor.
4. Map: the scale bar sits just right of the toolbar; the "to terrain" button is visible right of the sidebar.
5. Resize the window: the map stays crisp (no stretched canvas).

[ ] pass / [ ] fail

## D-07 Map options in the sidebar

1. Draw road, Building, Eraser options and the Select panel appear in the sidebar.
2. Select with nothing selected, and Move node, show a muted hint; the sidebar never disappears.

[ ] pass / [ ] fail

## D-08 Tooltips

1. Hover a button: a small translucent pill appears after about 0.7 s.
2. Tools with long help swap to the long text about 1.5 s later.
3. The tip fades after about 3 s while still hovering and returns only after leaving and re-entering.
4. Help > Tooltips off hides them; reload and confirm the choice persists.

[ ] pass / [ ] fail

## D-09 Compact steppers

1. Check steppers in: sidebar options, terrain File > New area popup, map image-import dialog, map new-map width/height.
2. Each is a compact box with up/down arrows inside.
3. Arrow click steps once; hold repeats; Shift = coarse.

[ ] pass / [ ] fail

## D-10 Scrub, type and wheel on value boxes

1. Drag sideways on a value: steps about 8 px per step; Shift = coarse.
2. Plain click puts the caret in for typing; Enter or blur commits; nonsense text reverts.
3. Wheel over the box steps it and does not zoom the map.
4. After a scrub, letter hotkeys and [ ] work immediately; [ ] still change the active value.

[ ] pass / [ ] fail
