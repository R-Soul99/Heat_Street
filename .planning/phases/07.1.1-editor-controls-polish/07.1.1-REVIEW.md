# Phase 07.1.1 Code Review

Sidebar / ResizeObserver / canvas-offset refactor looks sound: canvas-local mouse math already uses `rect.left`; `#road-problems` lives inside the offset `#wrap`; pure helpers (stepper, tip-phase, tool-groups, dock, canvas-point) have no logic bugs.

## Warnings

### WR-01: Stepper arrow buttons react to any pointer button
**Status: fixed (3cc06c4)**
**File:** `tools/editor-shell/controls.ts` (`hold()` pointerdown handler)
Right/middle click applies a step and starts auto-repeat; `canScrubFrom` checks `e.button === 0` but `hold()` doesn't.
**Fix:** `if (e.button !== 0) return;` at top of the handler.

### WR-02: Arrow auto-repeat captures Shift only at press time; no stop on lost pointerup
**Status: fixed (7fea3d3); Shift-at-press left as is**
**File:** `tools/editor-shell/controls.ts`
`shift` read once at pointerdown (scrub/wheel read live `e.shiftKey`). Interval keeps running if pointerup is lost (window blur mid-hold).
**Fix:** Stop repeat on window `blur` / `lostpointercapture`; optionally track Shift live.

### WR-03: Stepper wheel handler blocks sidebar scrolling
**Status: skipped (user decision pending UAT)**
**File:** `tools/editor-shell/controls.ts`
Wheel over any `.value-box` always `preventDefault()`s, so the `overflow-y: auto` sidebar can't scroll while over a stepper and a passing trackpad scroll changes values.
**Fix:** Gate on focus or a modifier. NOTE: UI-SPEC/D-10 specify hover-only wheel stepping; this was already flagged as a UAT judgement question — left for the user.

### WR-04: Visible label differs from aria-label
**Status: fixed (30104e7, 32cc5a0)**
**File:** `tools/editor-shell/tool-rail.ts`, `tools/terrain-editor/rail-tools.ts`
`aria-label = t.label` overrides visible `shortLabel` ("Smooth box" announced as "Smooth area"; Paint/Surface paint, Road/Road brush, Erase/Erase road, Lock/Lock/unlock road).
**Fix:** Name smoothBox consistently; set `aria-label` from `displayLabel` (+ key hint) or drop it for buttons with visible text.
