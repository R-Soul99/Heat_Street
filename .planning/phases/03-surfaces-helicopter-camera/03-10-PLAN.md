heavy tan dust off gravel, brown spray off mud, green flecks off grass — plus skid

    Implementation requirements:
    - ONE `THREE.Points` object per surface (six total), each with its own `THREE.PointsMaterial`
      configured `map: puffTexture, color: profile.colour, transparent: true, depthWrite: false,
      sizeAttenuation: true, size: profile.particleSizeM`. Do NOT build one shared system with a
      per-particle surface attribute — 03-RESEARCH.md's "Anti-Patterns to Avoid" rules that out
      for this phase's simple sprite scope.
    - FIXED pool of 96 particles per surface, allocated ONCE at construction as
      `Float32Array` position and age/lifetime buffers inside a `THREE.BufferGeometry`. Never
      `push`, never reallocate, never grow. A pool that is full simply does not emit — this is the
      ASVS V5 / DoS control 03-RESEARCH.md's Security Domain table names, and it must hold even if
      the slip signal is adversarial or `NaN`.
    - The soft round puff texture is generated at runtime from an offscreen `document.createElement("canvas")`
      radial gradient into a `THREE.CanvasTexture`, ONE texture shared by all six materials. No
      shipped PNG, no network fetch. Note in a comment that the shared texture is safe precisely
      because per-surface distinctness comes from the five axes above, not from the sprite shape,
      and that a single small PNG under `public/` is the documented fallback if runtime generation
      proves awkward (03-RESEARCH.md Assumption A6).
    - Emission gating, 03-RESEARCH.md's stated mechanism: emit from a wheel only when it is
      grounded AND its slip magnitude exceeds that surface's `slipThreshold`. Emission RATE scales
      with how far slip exceeds the threshold, so a bigger slide on gravel throws more dust —
      this is what delivers D-05's "heavy matching dust" without inventing a second metric. Carry
      fractional emission across frames in an accumulator so the rate is frame-rate-independent.
    - Only the systems whose surface at least one wheel is currently on may emit (Pitfall 5). An
      idle system with zero live particles costs effectively nothing; six simultaneously EMITTING
      systems is the real case to budget for, and it can happen legitimately when the car
      straddles a zone boundary diagonally.
    - Per-frame integration: advance each live particle's age by `dtSec`, move it by its rise and
      gravity, fade its alpha over its lifetime, and retire it by swapping it with the last live
      particle and decrementing the live count — the standard compaction that keeps the buffer
      contiguous with no allocation. Set `geometry.setDrawRange(0, liveCount)` and mark the
      position attribute needing update.
    - `update` allocates NOTHING. Reuse module-scope scratch `THREE.Vector3`s, matching
      `vehicle-view.ts`'s `SCRATCH_AXLE` convention.
    - `dispose()` disposes all six geometries, all six materials and the shared texture, one line
      each, copying `vehicle-view.ts` lines 338-349's structure.
    - Layering: this file reads sampled state passed in as plain values and writes only to objects

    deferred evolution of this system, so the sprite approach reads as a deliberate stage rather
