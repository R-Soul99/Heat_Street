<objective>
Give the six surfaces distinct voices, and stand up the project's first audio system
while doing it.

Purpose: SURF-02's other half. There is no `THREE.AudioListener` or `PositionalAudio`
anywhere in `src/` today — CONTEXT.md D-10 notes this is the project's first audio
system built from scratch, and CLAUDE.md already names it as shared infrastructure a
later phase's engine-RPM crossfade will reuse. The system ships working with
procedurally synthesized loops so it is never blocked on asset acquisition, and has a
file-loading path ready for real CC0 recordings the moment a human has verified their
licenses.

rule for it, and a `CREDITS.md` for any committed asset.
