    - A 130x70-cell grid builds ceil(130/64) * ceil(70/64) = 3 * 2 = 6 chunk meshes; vertex count of a full chunk is 65*65.
    - Every chunk vertex position equals (originX + col*cell, heights[terrainIndex(row,col)], originZ + row*cell) exactly.
    - For each quad, the two triangles in the index buffer split along TERRAIN_DIAGONAL (test reads the indices of quad (0,0)).
    - Vertices duplicated on a border between two chunks have identical positions and identical normals (toBeCloseTo 9).
    - chunkAt(x, z) returns the chunk covering that point and undefined outside the grid.
    - rebuildRegion(minRow, minCol, maxRow, maxCol, { heights: true }) after editing heights updates positions/normals of exactly the chunks overlapping the region expanded by 1 cell (returns the rebuilt chunk count; a 2x2-cell region in the middle of chunk 0 returns 1).
    - dispose() disposes every geometry, material and texture it created (spy on dispose).
  </behavior>
  <action>
Create `src/render/terrain-view.ts` (imports `three` and pure `src/core` only; no Rapier, no world.step). Export `TERRAIN_CHUNK_CELLS = 64`, `TERRAIN_SURFACE_PALETTE: Readonly<Record<SurfaceType, number>>` with the UI-SPEC hex values, and `interface TerrainView { readonly group: THREE.Group; readonly chunkMeshes: readonly THREE.Mesh[]; readonly crestMeshes: readonly THREE.Mesh[]; chunkAt(x: number, z: number): THREE.Mesh | undefined; rebuildRegion(minRow: number, minCol: number, maxRow: number, maxCol: number, what: { heights?: boolean; paint?: boolean }): number; updateTextures(focusX: number, focusZ: number): void; dispose(): void }`.
Export `buildTerrainView(grid: TerrainGrid, paint: PaintMap, opts?: { chunkCells?: number; palette?: Partial<Record<SurfaceType, number>>; textureRadiusM?: number; crests?: readonly AuthoredCrest[] }): TerrainView`.
Geometry: one `BufferGeometry` per chunk with position, normal and uv attributes (uv maps the chunk's world rectangle 0..1 for its paint texture), indices split per `TERRAIN_DIAGONAL` (must match the plan 01 sampler and hence Rapier). Normals from `terrainVertexNormal` on the GLOBAL grid (never `computeVertexNormals` per chunk — RESEARCH anti-pattern, Pitfall 5). Material: `MeshStandardMaterial` (roughness 0.95, metalness 0) per chunk with `map` = that chunk's paint texture; `receiveShadow = true`. Call `geometry.computeBoundingSphere()` after building/rebuilding so frustum culling works. Crest meshes: build from `buildCrestGeometry(opts.crests, (x, z) => sampleHeightfieldBilinear(grid, x, z))` (same sampler as plan 02 physics), returned in `crestMeshes` and NOT added to `group` (mirrors MapWorldView.crestMeshes, caller decides). Write the geometry tests first.

  <behavior>
    - A chunk within textureRadiusM (default 600 m) of the focus point after updateTextures has a full-resolution DataTexture whose size equals the chunk's paint pixel span; a chunk outside the radius has a low-resolution texture of one texel per cell.
    - Moving the focus far away and calling updateTextures downgrades the old chunk's texture (the full-res texture is disposed) — at most chunks within radius hold full-res textures.
    - A texel over a pixel encoded ("grass", false) has the grass palette colour; a texel encoded ("tarmac", true) differs from a texel encoded ("tarmac", false) (road tint applied).
    - Textures use LinearFilter for min and mag (soft edges, brief) and SRGBColorSpace.
    - rebuildRegion(..., { paint: true }) re-uploads only the textures of overlapped chunks (needsUpdate set on exactly those).
  </behavior>
  <action>
In `src/render/terrain-view.ts` add paint texture management: per chunk, a full-resolution RGBA8 `THREE.DataTexture` built from the paint pixels covering the chunk rectangle (palette colour per decoded surface; road-flag pixels are drawn with a road tint: lerp the surface colour 35% toward 0x3a3d42 so painted roads read on tarmac ground, RESEARCH paint-map note + feel-test visibility), or a low-res texture (one texel per cell, sampled at cell centres) when the chunk is outside `textureRadiusM` of the last `updateTextures(focusX, focusZ)` call. `magFilter`/`minFilter` = `THREE.LinearFilter`, `generateMipmaps = false`, `colorSpace = THREE.SRGBColorSpace`, `flipY = false`, UVs matching Task 1.
