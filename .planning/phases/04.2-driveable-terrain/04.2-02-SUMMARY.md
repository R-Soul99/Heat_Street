# Phase 04.2 Plan 02: Terrain physics scene Summary

One FIX_INTERNAL_EDGES heightfield collider per area with per-wheel surface read from the paint map at each wheel's contact point, returning the existing `MapScene` contract.

## Commits

- c3591f3 feat(04.2-02): position-based per-wheel surface lookup from the paint map
- 8fd6261 feat(04.2-02): terrain scene builder returning the MapScene contract

## What was built

- `SurfaceContext.paint?` (additive). In the vehicle grip loop, a wheel whose ground collider handle equals `paint.colliderHandle` reads `wheelContactPoint` into one scratch vector allocated at vehicle creation; a null contact keeps the previous surface. All other wheels use the legacy `SurfaceMap.lookup`. With `paint` undefined the path is unchanged.
- `terrain-scene.ts`: heightfield with `HeightFieldFlags.FIX_INTERNAL_EDGES` and `ROAD_FRICTION`, bilinear-sampled crest trimeshes, building cuboids, spawn at `sampleTerrainHeight + 0.6`, a named error if no default spawn and no override.
- `map-scene.ts` now exports `SPAWN_CLEARANCE_M`, `BUILDING_FRICTION`, `ROAD_FRICTION`, `DEFAULT_SPAWN_ID`, `buildBuildingCollider`, `yRotationQuat` (values unchanged).
