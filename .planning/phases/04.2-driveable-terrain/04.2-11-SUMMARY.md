# Phase 04.2 Plan 11: Terrain Converter Summary

Deterministic converter turns feel-test, grid-test and juliette-ga compiled maps into terrain artifacts (levelled road bands, rasterised paint, verbatim graph) and the game now opens them through the terrain loader.

## Tasks

1. Pure converter and tests (commit d4533de): `convertCompiledArea`, `convertHeights`, `CONVERT_CONFIG`; 16 tests in `tests/terrain-convert.test.ts` (graph identity, routes valid for all three, edge-midpoint paint and heights, grid-test off-road heights vs legacy within 0.01 m, juliette and grid-test node/point/midpoint heights within 0.02 m, encode/load round trip, feel-test 600-tick legacy-vs-terrain drive within 1%). Runs in about 1.5 s.
2. CLI, artifacts, MAP_FORMATS (commit d71b6ba): `npm run convert-terrain -- --area <feel-test|grid-test|juliette-ga|all>`; anything else exits 2. Second run produced identical sha256 for all six files.
