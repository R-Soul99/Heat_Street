# Phase 04.2 - UI Design Contract

> Scope: one developer-only 3D terrain sculpt page (`tools/terrain-editor/`, served by the Vite dev middleware, never shipped to players) plus the debug-only prototype-gate/drive-here hooks in the game. There is no player-facing UI in this phase. The contract deliberately clones the existing 2D map editor (`tools/map-editor/index.html`) so the two tools feel like one family. Proportionate to a dev tool: no new design system.

Sources: CONTEXT.md D-09..D-16 (tools, undo, drive here), brief (orbit + top-down, brushes), `tools/map-editor/index.html` + `editor.ts` (baseline styling), `src/core/surface-types.ts` (surface enum). Items marked ASSUMPTION are defaults chosen without user input.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla TypeScript + DOM, no framework; per CLAUDE.md) |
| Preset | not applicable |
| Component library | none; hand-written HTML/CSS in a single inline `<style>` block copied from `tools/map-editor/index.html` |
| Icon library | none; text labels only (as in the 2D editor) |
| Font | `system-ui, sans-serif` for UI; `monospace` for log/readouts |
| Debug panel | lil-gui (`three/addons/libs/lil-gui.module.min.js`) only for in-game slope/terrain readouts if needed; the sculpt page itself uses the hand-written side panel |

Layout (clone of map editor): `#app` flex row; `#wrap` (flex:1, contains the WebGL `<canvas id="view">`) on the left; `#side` fixed 300px right column, `overflow-y:auto`, background `#1d2026`, 1px `#333` left border. ASSUMPTION: panel stays 300px wide to match the 2D editor.

Side panel section order (top to bottom, `<h3>` headings): Tool, Brush options (`#tool-opts`), Area, Camera, Status/hint, Selection/readout, Legend, Log.

## Color

Taken from the 2D editor so both tools match.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#14161a` | Page background, canvas clear colour, log well `#0c0d10` |
| Secondary (30%) | `#1d2026` | Side panel; inputs `#111`; buttons `#2d3440` (hover `#3a4456`); borders `#333`/`#444`/`#556`; body text `#ddd`, labels `#9aa` |
| Accent (10%) | `#2f6f55` fill / `#6c9` border | Active tool button, primary-action border `#4a8` |
| Destructive | `#a44` | Border of erase / discard-type buttons only |

Accent reserved for: the currently active tool button; the border of Save and Drive here (`primary`); the brush-cursor ring on terrain. Never used for generic hover or labels.

Warning colour `#fb4` (existing `.dirty`): unsaved-changes marker and slope-limit-hit flash only.

Surface paint colours (existing, from `editor.ts`; reused for the paint-map preview and legend swatches so a surface looks the same in both editors): tarmac `#8d939c`, gravel `#c9b27a`, dirt_road `#a8743f`, grass `#5da04a`, sand `#e6d58a`, mud `#5b4330`. Terrain base shading is lit `MeshStandardMaterial`/vertex-tinted by paint map, with the paint map rendered smoothed with soft edges per the brief.

Brush overlay: ring colour `#6c9`, 2px, depth-test off. Slope-limit-exceeded: brush ring turns `#fb4` while the stroke is being clamped (D-03).

## Interaction Contract

Camera
- Orbit: right-mouse drag (ASSUMPTION; left is reserved for the brush). Pan: middle-mouse drag or Shift+right drag. Zoom: wheel.
- Top-down toggle: button `Top-down (T)` toggles between the last orbit pose and a straight-down orthographic-style view; second press restores the orbit pose.

Tools (single active, shown as `button.tool.active`; shortcuts mirror the 2D editor's single letters and are ignored while a text/number input has focus):

| Tool | Key | Behaviour |
|------|-----|-----------|
| Raise / lower | H | Left-drag raises; Alt+drag lowers. Falloff to neighbours; clamped by global max slope (~35 degrees, D-03) |
| Smooth | G | Drag to average heights under the brush |
| Flatten | F | Click sets target to height under cursor; drag levels to it |
| Surface paint | P | Paints the selected surface (6-type enum) into the paint map; plain paint does not create graph edges |
| Road brush | R | Drag lays one stroke: paint + level + graph edge. Options: class preset, width slider, bank max (off on streets) |
| Stamp | S is Save, so use W | Wedge / mound stamp, click to place, scroll or [ ] to rotate, drag to size. ASSUMPTION: key W |
| Erase road | E | Removes paint and splits/deletes graph edge; levelled terrain stays (D-15) |

Brush options (`#tool-opts`): Radius (number + range, metres, default 12), Strength (0..1, default 0.5), Falloff (linear / smooth select, default smooth). Surface select shown only for Surface paint and Road brush.

Actions (buttons in the Area block, same order and style as 2D editor):
- Undo (Ctrl+Z) and Redo (Ctrl+Shift+Z or Ctrl+Y). 50 strokes deep, one entry per mouse-down to mouse-up (D-11). Disabled state when stack empty (opacity .5, no pointer events).
- Save (Ctrl+S), class `primary`. Writes versioned binary + JSON sidecar via the dev middleware. Header shows `unsaved` marker (`.dirty`) after any stroke.
- Load: area select + `Load` button; prompts to discard if dirty (reuse `confirm("Discard unsaved edits?")` pattern).
- Drive here (D), class `primary`: saves first, then opens the game in a new tab at the cursor position, no compile step (D-12). If the cursor is off the terrain, uses the camera orbit target.
- New area: dialog-free; `New...` button reveals name, size (m, max 2000 x 2000) and cell size (m, default 3) inputs in the panel, then `Create`.

Road brush class presets (ASSUMPTION values, tuned in planning): Street (width 8m, 2 lanes, tarmac, bank off), Highway (12m, 2 lanes, tarmac, bank max 8 degrees), Track (6m, 1 lane, gravel, bank max 6), Dirt road (5m, 1 lane, dirt_road, bank off). Width slider range 3 to 20m, step 0.5.

Readout block (`#sel`, 11px monospace) updates on cursor move: world x/z, height (m), slope (degrees), surface type, nearest graph edge id. Shows vertex/chunk count and last edit ms for the frame-budget check (D-04).

Feedback rules: strokes apply live while dragging (chunk-wise mesh update, no full rebuild); status line shows the last action ("Saved my-hills v1, 412 KB"); the log well receives any converter or validator output verbatim.

Accessibility: dev tool, mouse + keyboard only. Every button is a real `<button>` with a text label; focus outline left at browser default; no colour-only state (active tool also gets `aria-pressed="true"`).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Drive here |
| Save CTA | Save terrain |
| Empty state heading | No area loaded |
| Empty state body | Pick an area from the list or press New... to start a flat 1000 x 1000 m terrain. |
| Error state (save) | Save failed: {server message}. Your edits are still in memory; fix the problem and press Save terrain again. |
| Error state (load/version) | Cannot load {file}: unknown format version {n}. Open it with a newer build or restore the previous file. |
| Error state (graph) | Road graph invalid: {validator message}. Undo the last stroke or erase the road and repaint. |
| Hint (slope hit) | Slope limit reached ({max} degrees). Lower the radius or flatten the area first. |
| Hint (default) | Left-drag to sculpt. Right-drag to orbit, middle-drag to pan, wheel to zoom. |
| Destructive confirmation | Discard unsaved edits?: You have unsaved changes to {area}. Discard them and continue? (browser `confirm`) |
| Erase road confirmation | None; recoverable via Undo (D-15). Status line: "Road erased. Ctrl+Z to undo." |
| Overwrite on New | Area {name} already exists: Overwrite it? (browser `confirm`; default Cancel) |

Tone: terse, factual, sentence case, no emoji.
