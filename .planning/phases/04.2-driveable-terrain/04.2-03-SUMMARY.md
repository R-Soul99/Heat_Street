# Phase 04.2 Plan 03: Terrain area format Summary

Versioned little-endian terrain binary (HSTR header, 16-bit quantised heights, raw or deflate-raw paint) plus a JSON sidecar carrying the road graph v1 verbatim, crest objects, buildings and id counters, with one combined loader and a normative schema doc.
