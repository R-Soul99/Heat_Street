# Phase 04.2 Plan 08: Terrain road-graph edit ops Summary

Pure, immutable road-graph editing (add stroke with auto-junctions, erase disc, replace on repaint, node compaction with spawn remap) that emits unchanged road-graph v1 and passes `parseRoadGraph` plus the real `validateGraph`.

## What was built

- `addRoadStroke(state, polyline, profile, {snapM, replace})` returns a new state, `newEdgeIds`, `junctionNodeIds`, and a `reason` when the stroke is rejected (fewer than 2 distinct finite points, NaN) with the state returned unchanged (T-04.2-22).
- `findStrokeCrossings(state, polyline, halfWidthM, opts)` and `addRoadStroke` share one internal planner (`planStroke`), so reported cross / snap-edge / snap-node x/z equal the junction node x/z exactly (asserted in tests).
- `eraseGraphDisc` splits at disc boundaries via segment-circle intersection, first surviving piece keeps the original id, cut ends become dead-end nodes, orphans dropped and ids compacted.
- `compactNodes` returns the same graph object when nothing is orphaned; otherwise dense renumber with edges and spawns remapped (spawn on a deleted node moves to the nearest survivor, heading along its first edge; no nodes left gives `spawns: []` and `spawnLost: true`).
- `ensureDefaultSpawn` adds `default` at node 0 facing along its first edge (yaw via `yawFromTravelDirection`).
- `graph.bounds` is never touched.

## Decisions

- A split edge's FIRST half keeps the original id; the second half (and later pieces) gets a fresh `nextEdgeId++`. Routes referencing a split edge id still start on valid road.
- `junctionNodeIds` means newly created junction nodes (cross and snap-edge); reuse of an existing node is not listed. In replace mode (which compacts) the ids are remapped to post-compaction ids.
- Replace mode compacts orphan nodes, so node ids can change on a replace add (plain add never renumbers). `findStrokeCrossings` with `replace` ignores to-be-removed edges but reports pre-edit node ids.
- `StrokeJoin` snap-node `endpoint` also allows `"through"` for an interior stroke point passing exactly over an existing node (no zero-length split).
- `eraseGraphDisc.removedEdgeIds` lists edges deleted outright; partially erased edges are not listed.
- A junction/crossing point's y is the mean of the stroke and existing edge y; the split edge's point is moved to that y.
