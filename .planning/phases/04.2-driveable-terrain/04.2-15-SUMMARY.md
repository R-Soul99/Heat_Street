# Phase 04.2 Plan 15: Medal re-record and migration docs Summary

A debug-only console line now prints a paste-ready medal reference from any completed run. The user drove four designer reference runs with it on the migrated juliette-ga and grid-test terrain maps, and those values are now the shipped (provisional) medal references. Every legacy-vs-terrain difference is documented, ADR 0001 is amended, the slopes re-verification is recorded in the tuning guide, and Phase 4.1 is closed as absorbed.
