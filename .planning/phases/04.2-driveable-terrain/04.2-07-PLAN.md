  <behavior>
    - A single 50 m spike on a flat 40x40 grid (cell 3 m) limited at 35 degrees ends with every axis-neighbour delta <= tan(35°)*3 + 1e-6 and every diagonal delta <= tan(35°)*3*sqrt(2) + 1e-6.
    - Cells outside the returned window are byte-identical before and after.
    - The spike's peak cell is lowered (not neighbours raised indefinitely); total changed cells are reported as indices.
    - With a mask marking a 5-cell band as road, masked cells keep their exact height; if the mask makes the constraint unsatisfiable, `limitSlope` returns `roadViolations > 0` instead of moving road cells.
    - maxSlopeDegIn(grid, window) returns the steepest axis-neighbour slope in degrees (35 ± 0.01 for a plane built at exactly the cap).
    - expandWindow(window, grid, maxDeltaM, maxSlopeDeg) grows the window by ceil(maxDeltaM / (tan(slope)*cell)) cells, clamped to the grid.
    - Running on a 667x667 grid with a 20x20 changed window touches only the expanded window (performance guard: completes under 50 ms in the test).
  </behavior>
  <action>
Create `src/core/terrain-slope.ts` (pure, `.ts` specifiers). Export `interface CellWindow { minRow; minCol; maxRow; maxCol }` (inclusive vertex indices), `expandWindow`, `maxSlopeDegIn`, and `limitSlope(grid, window, opts: { maxSlopeDeg?: number; mask?: Uint8Array; iterations?: number }): { changed: Uint32Array; roadViolations: number }`. Algorithm (RESEARCH): forward raster sweep (row asc, col asc) relaxing each non-masked vertex against its already-visited W, N, NW, NE neighbours with h = clamp(h, hn − d*dist, hn + d*dist) where d = tan(maxSlope) * cell and dist is 1 or sqrt(2); then a backward sweep against E, S, SE, SW; repeat until no change or `iterations` (default 4). Masked vertices are sources only. After the sweeps, check masked pairs against the cap and count violations. Default maxSlopeDeg = MAX_SLOPE_DEG. Windowed: never touch vertices outside the window (RESEARCH anti-pattern: no global pass per stroke).
