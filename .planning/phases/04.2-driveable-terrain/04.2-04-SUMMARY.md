# Phase 04.2 Plan 04: Terrain render view Summary

Chunked terrain meshes (64x64 cells) whose triangles split along `TERRAIN_DIAGONAL` with grid heights verbatim, so render equals physics; normals come from the global grid (`terrainVertexNormal`), so chunk borders are seam-free.

## What was built

- `buildTerrainView(grid, paint, opts)` returning `{ group, chunkMeshes, crestMeshes, chunkAt, rebuildRegion, updateTextures, dispose }`.
- Paint textures: RGBA8 DataTexture per chunk, LinearFilter, sRGB, no mipmaps. Full resolution (paint pixel span) only within `textureRadiusM` (default 600 m) of the last `updateTextures` focus; otherwise one texel per cell. Replaced textures are disposed immediately (T-04.2-10). Road-flag pixels are lerped 35% toward 0x3a3d42.
- `rebuildRegion` rebuilds only overlapped chunks (heights: region expanded by 1 cell so border neighbours update; paint: re-uploads in place and sets needsUpdate).
- Crest meshes built from `buildCrestGeometry` with the bilinear sampler, not added to `group`.
