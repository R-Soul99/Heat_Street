  <behavior>
    - TOOL_KEYS maps KeyH->raise, KeyG->smooth, KeyF->flatten, KeyP->paint, KeyR->road, KeyW->stamp, KeyE->erase.
    - raise tool: down + 3 moves + up on a flat area produces ONE undo entry; heights near the path increased; with alt=true heights decrease.
    - Every down/move returns { dirty: CellWindow | rect, slopeClamped } so the editor can rebuild only those chunks and colour the ring.
    - flatten: pointer-down records target = height under cursor; moves level toward it.
    - paint: writes the selected surface without a road flag and creates no graph edges.
    - road: moves only collect points (no terrain change until up; returns preview points); up calls applyRoadStroke with the selected preset/width/bank; one undo entry; undo restores heights, paint and graph exactly.
    - erase: up/down at a point calls eraseRoad with the brush radius; status text "Road erased. Ctrl+Z to undo." returned when an edge was removed.
    - stamp: click places at cursor with current rotation and size; rotate(+/-) changes rotation by 15 degrees; drag from down to up sets lengthM to the drag distance (min 4 m).
    - Undo/redo through the dispatcher's stack is 50 deep and returns dirty regions; a new stroke after undo clears redo.
    - Non-finite pointer coordinates are ignored (no op, no undo entry).
  </behavior>
