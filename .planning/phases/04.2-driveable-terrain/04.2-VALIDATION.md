## Sampling Rate

- **After every task commit:** Run the task's `<automated>` command (listed below) plus `npm run typecheck`
- **After every plan wave:** Run `npm run check`
- **Before `/gsd-verify-work`:** Full suite must be green, `npm run feel-dossier` within tolerance, human gate sign-off recorded, profiler HUD reading recorded against `docs/frame-budget.md`
- **Max feedback latency:** 60 seconds
