# Phase 04.2 Plan 13: Sculpt tools wiring Summary

Every v1 tool (raise/lower with Alt, smooth, flatten, surface paint, road brush, erase road, wedge/mound stamp) now works in the terrain sculpt page through a DOM-free dispatcher with one undo entry per mouse stroke.

## Tasks
1. Tool dispatcher + 12 tests: 58e314b
2. DOM wiring (options panel, shortcuts, live rebuild, validator log, Drive here): 48a0800

## What was built
- `tool-dispatch.ts`: dabs spaced radius/4, flatten target captured on pointer-down, road moves only preview until release then `applyRoadStroke`, erase via `eraseRoad`, stamp rotate 15 degrees, non-finite coordinates ignored, 50-deep undo/redo, `clearHistory`.
- `editor.ts`: left-button strokes with pointer capture, `rebuildRegion` on dirty windows only, amber ring plus slope hint while clamped, road preview line, `Road graph invalid: ...` log (reachability downgraded to info), Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y / Ctrl+S, tool keys by `e.code`, `[`/`]` stamp rotation, history cleared on load/create, last-edit ms readout.
- Drive here (D): allowlist check via `KNOWN_MAP_IDS` + `MAP_FORMATS === "terrain"`, saves first, then `window.open("/?map=<id>&at=x.x,z.z&debug")` at the cursor hit (orbit target fallback).
