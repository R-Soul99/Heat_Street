### `src/core/terrain-grid.ts` (utility, transform)

**Analog:** `src/core/heightfield-sample.ts`

Keep the exact structural interface so the new grid can feed `buildCrestGeometry`/old sampler unchanged (lines 17-25):
```typescript
export interface SampleableHeightfield {
  readonly rows: number;
  readonly cols: number;
  readonly heights: ArrayLike<number>;
  readonly originX: number;
  readonly originZ: number;
  readonly scaleX: number;
  readonly scaleZ: number;
}
function heightAt(grid: SampleableHeightfield, row: number, col: number): number {

}
```

## Shared Patterns

### Layering (applies to every new `src/` file)
**Source:** `tests/layering.test.ts` (globs `../src/**/*.ts` via `?raw`, lines 18-40); enforced mechanically.
- `src/core/`: no `three`, `@dimforge/rapier3d`, DOM, fs, wall clock.
- `src/physics/`: Rapier + core only; no `three`, no DOM, no network (fetch lives in `main.ts`).
- `src/render/`: reads sim state, no Rapier import, no `world.step`.
Comment lines mentioning forbidden patterns are exempt (`isCommentLine`).
Note: `tools/**` is NOT scanned, so the sculpt page may use `three`, but must still import only pure `src/core` code for data logic.

### Loud build failure, graceful runtime query
**Source:** `src/core/heightfield-sample.ts` lines 31-38 (clamp) and `src/physics/map-scene.ts` `resolveSpawn` lines 323-343 (throw naming area).
