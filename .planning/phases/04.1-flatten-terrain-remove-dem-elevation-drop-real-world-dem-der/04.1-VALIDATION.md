> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 5.0.0 (pinned in `package.json`) |
| **Config file** | `vitest.config.ts` |

| **Full suite command** | `npm run test` (also `npm run check` for typecheck+lint+test) |
| **Estimated runtime** | ~30 seconds (quick), ~2 minutes (full suite incl. typecheck+lint) |

---

## Sampling Rate

- **After every task commit:** Run `npx vitest run` scoped to the files touched by that task (elevation, heightfield, road-geometry, shoulder-clearance, collision, gltf, cli as applicable)
- **After every plan wave:** Run `npm run check` (full typecheck + lint + full suite)
- **Before `/gsd-verify-work`:** Full suite must be green AND D-06's full human drive-every-road SC1-equivalent re-verification session must be completed
- **Max feedback latency:** 30 seconds
