## Flatness target

### Q1: How flat should the terrain be?

| Option | Description | Selected |
|--------|-------------|----------|
| Dead flat everywhere | Y=0 constant for roads and off-road terrain, deletes most elevation.ts/shoulder-clearance.ts machinery | |
| Capped gentle relief | Small hand-authored variation, hard-capped (~2-3m) so shoulders never bridge more than a trivial gap | ✓ |

**User's choice:** Capped gentle relief
**Notes:** Initially appeared to conflict with the next two answers (literal zero generator, roads flat too) — resolved in a follow-up question below.

### Follow-up: Where does the relief actually show up (resolving the apparent contradiction)?

| Option | Description | Selected |
|--------|-------------|----------|
| Nowhere yet — ship fully flat now | Roads and terrain both y=0; "capped gentle relief" describes a door left open for later | |
| Off-road terrain only, away from roads | Roads stay flat; off-road heightfield gets small capped procedural variation for visual texture | ✓ |

**User's choice:** Off-road terrain only, away from roads
**Notes:** Reconciles all four answers — roads are flat (y=0), off-road terrain gets the capped relief.

### Q2: What generates the terrain height, now that DEM sampling is gone?

| Option | Description | Selected |
|--------|-------------|----------|
| Literal constant zero | No generator needed — every node/point gets y=0 | ✓ |
| Deterministic procedural function | Seeded low-amplitude noise shapes gentle variation automatically | |
| Fully hand-authored per-area | Explicit height values/curves placed manually | |

**User's choice:** Literal constant zero
**Notes:** Applies as the flat baseline (roads + the off-road relief's zero-point); the off-road relief itself still needs an actual generator per the follow-up amplitude question below.

### Q3: Should road elevation vary at all, or be flat/level everywhere too?

| Option | Description | Selected |
|--------|-------------|----------|
| Roads flat too | Every road node gets y=0 | ✓ |
| Roads keep gentle real grade | Roads retain some elevation change even if off-road terrain is flat | |

**User's choice:** Roads flat too

### Q4: How large should the off-road terrain's capped relief be, and how should it taper toward roads?

| Option | Description | Selected |
|--------|-------------|----------|
| ±2m cap, fades to 0 within shoulder width | Subtle rolling far from roads, zero at paved edge | ✓ |
| ±5m cap, fades to 0 within shoulder width | More visible rolling hills, wider transition zone needed | |
| You decide | Claude picks a reasonable default, tuned empirically like Phase 4's constants | |

**User's choice:** ±2m cap, fades to 0 within shoulder width
