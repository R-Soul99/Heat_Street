# Phase 04.1 Plan 08: Rewire Compiler CLI and Delete the DEM Pipeline Summary

**`tools/map-compiler/cli.ts`'s composition root is rewired onto the flat-terrain stage set (`applyFlatElevation`, `buildOffRoadRelief` moved ahead of the building stage, `GroundHeightSampler`-seated buildings, `buildCrestGeometry` wired into the `.glb`), and every remaining DEM fetch/parse/cache/sampler module, the cached raw GeoTIFF and the orphaned `geotiff` npm dependency are deleted — `npx tsc --noEmit` and `npm run check` are both green for the first time since phase 04.1 wave 1.**

## Accomplishments

- `tools/map-compiler/cli.ts`: import block, header pipeline description, and `main`'s stage sequence rewritten to the flat-terrain order — `applyFlatElevation(graph)` replaces the retired `loadOrFetchDem`/`parseDemRaster`/`makeElevationSampler`/`applyElevation` block; `buildOffRoadRelief(flatGraph, flatGraph.bounds)` moved ahead of `buildingBoxes`, which now takes a `(x, z) => sampleHeightfieldBilinear(heightfield, x, z)` `GroundHeightSampler` instead of the old lat/lon DEM sampler; `buildCrestGeometry(crestsForArea(config.areaId), sampler)` is a new stage feeding `buildGltfDocument`'s fifth `crests` parameter.
- `printElevationReport` replaced with `printFlatElevationReport(report: FlatElevationReport)`, printing node/edge/point counts, `totalEdgeLengthM`, and `maxAbsNodeY`/`maxAbsPointY` (both to 3 decimals) with an explicit `console.warn` branch if either is nonzero — the regression signal that D-01's flatness held.
- `printGltfSummary` extended to print `crests: <N> crest(s), <M> triangles`.
- The resolved-area log line's `demSource "${config.demSource}"` fragment replaced with `terrain "flat-authored"`.
- `tools/map-compiler/sources/dem.ts`, `dem.test.ts` and the cached `juliette-ga.dem.tif` GeoTIFF deleted (`git rm`, confirmed staged as `D`, not untracked).
- `demSizePx` removed from `AreaConfig` and `julietteGaConfig` (its only remaining caller, the retired `exportImage` request, is gone); `demSource` is unchanged — plan 04.1-06 repurposed it and it stays a required schema field.
- `geotiff` removed from `package.json` devDependencies; `npm install` regenerated `package-lock.json` (93 lines removed — `geotiff` and its transitive deps only, no other pinned version changed).
- Verified the pipeline actually runs end-to-end: `npm run compile-map -- --area juliette-ga` completed with zero network calls, `flatness check: maxAbsNodeY=0.000 maxAbsPointY=0.000`, a 128x128 off-road relief grid (range -1.9m to 1.6m), and 3 authored crests (2208 triangles) baked into the `.glb` — then reverted the recompiled artifacts (see Deviations).
