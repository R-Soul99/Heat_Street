Export `interface CellBox { minRow; minCol; maxRow; maxCol }` (CELL indices, half-open `[min, max)`), `type MaskOp = "replace" | "add" | "subtract"`, and `createCellMask(rows, cols): CellMask` where `CellMask` has:
- `rows`, `cols`, `data: Uint8Array(rows * cols)` indexed `r + c * rows`;
- `apply(box: CellBox, op: MaskOp): void` (replace clears first; boxes clipped to the grid; non-finite or empty boxes ignored);

- `cellAtXZ(grid, x, z): boolean`;
- `boundarySegments(grid, lift): Float32Array` - flat `[x0,y0,z0,x1,y1,z1,...]` for every cell edge between a selected and an unselected (or off-grid) cell, y from `grid.heights` + lift; same format as `gridLineSegments`.
- `fillTriangles(grid, lift): Float32Array` - flat triangle positions (two triangles per selected cell, corners lifted onto `grid.heights` + lift) for the translucent selection fill (UI-SPEC "Selection visuals").
Also export `cellBoxFromWindow(win: CellWindow): CellBox` converting the dispatcher's inclusive vertex window (`windowBetween`) to cells `[minRow, maxRow) x [minCol, maxCol)` - convert once here (Pitfall 4).
The mask must have no polygon logic; everything is a scan over the bitmask. Max grid is 4M vertices, so one byte per cell is acceptable.
