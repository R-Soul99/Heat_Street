# Phase 07.1.2 Plan 11: Terrain sidebar per mode and old-tool removal Summary

The terrain sidebar is now rebuilt per mode and armed brush (`buildSidebar`), one swatch picker feeds both the Terrain fill and the Terrain brush, and every old tool and transitional API is gone from the editor, dispatcher and core.

## What was built

- **Select sidebar:** hint plus modifier line, Step, Smooth strength, Slope limit, Surface swatches, Selection size and Average height readouts (`maskAverageHeight`, "-" when empty), and an open "Roads" section (Re-grade selection, Re-grade all unlocked, Lock all, Unlock all, roads count row), all through `runLockAction`.
- **Brush sidebar:** Strength, Falloff and Slope limit for height ops; Surface swatches when Terrain is armed; Road class, Width and Max bank when road Paint is armed; Smooth also keeps its whole-map strength/passes controls and the Smooth whole map button; "Pick an operation." when nothing is armed. Radius and shape stay in the floating toolbar; `[ ]`, arrows and Alt+wheel adjust the floating brush size in Brush mode.
- **`surfaceSwatches()`:** `role="radiogroup"` of 32px `role="radio"` swatches (4 columns, 4px gap), palette colours from `TERRAIN_SURFACE_PALETTE`, `aria-label`/`data-tip` set to the surface name, writes `setOptions({ surface })`.
- **Sidebar rebuild** happens in `syncToolbar` only when the mode or armed operation changes; readouts update in place.
- **History pad** stays Undo, Redo, Clear selection (no `clearAll`). The view pad lost Grid/Contours (floating row owns them); Top-down stays.
- **Removed from the editor:** block/smooth-box/stamp previews, stamp arrow, `selectTool` hotkey block, stamp `[ ]` rotation, cyan road-selection overlay, `lockKey`, old flyout; `RAIL_TOOLS`/`RAIL_TOOL_IDS` from rail-tools.
- **Removed from the dispatcher:** `TOOL_KEYS`, `raiseSelection`, deprecated `getSelection`/`setSelection`, `cancelBoxDrag`, `smoothBoxWindow`, `lockClick`, road selection (`selectedEdgeId`, `getSelectedEdgeId`), `regradeSelected`, `rotateStamp`, `steppedBlocks`, and the `stamp*`/`block*` options with their clamps. `Tool` is now `BrushToolName | "select"`.
- **Removed from core:** `stampTerrain`, `StampParams`, `stampOutline`, `StampOutlineSpec` and their tests. `raiseBlock`, `blockWindowAt` and `BLOCK_*` stay (golden lock tests), with a comment saying so.
- **ShellTool:** deprecated `dock?` and `group?` removed.

## Deviations from Plan

**1. [Rule 3 - Blocking] `cancelSelectDrag` added to the dispatcher.** Esc and Clear selection still need to abandon a rubber-band drag, and the plan deletes `cancelBoxDrag`. A select-drag-only `cancelSelectDrag()` replaces it. Added in the Task 2 commit.

**2. [Rule 3 - Blocking] Task 2 commit includes a small dispatcher change.** To keep `tsc` green, the internal `gridSelect` tool was renamed to `select` in `tool-dispatch.ts` (and its test) in the Task 2 commit instead of Task 3.

**3. `setTool` kept** as a narrowed adapter (`BrushToolName | "select"`) onto setMode/armBrush: it has no editor callers but about 57 test call sites. The "deprecated" tag was dropped.

**4. [Rule 1] Locked-road hover** (`updateLockHover`) was gated on the removed Lock tool, so it would have been dead code. It now runs in Select mode (not while dragging or push/pulling) with a 4 m reach and no "click to lock" wording.

**5. `roadLockSegments` parameter renamed** `selectedEdgeId` to `highlightEdgeId` so the plan's removal grep is clean; the editor passes `null`. Behaviour unchanged.

**6. Test conversions:** block-based setup in the smoothAll and road-lock tests now uses a Select-mode `raiseBox` helper (select a box, `applyOperation("raise")`). Tests for removed tools (stamp, block, smoothBox, lock click, shift-select, regradeSelected, TOOL_KEYS, `has no docked tools`) were deleted. `getSelection` tests use `getSelectionMask().bounds()`.

**7. Added a "Max bank" stepper** to the road Paint sidebar (the plan lists bank among the road options; the old flyout had none). The old road-flyout Surface select was dropped because the dispatcher's road stroke never used it.
