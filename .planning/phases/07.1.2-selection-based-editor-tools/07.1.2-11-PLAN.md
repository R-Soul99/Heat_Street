  - Always: "Strength", "Falloff" (existing select) and "Slope limit".

  - Armed `roadPaint`: add the existing road options (preset, width, bank), moved from the old road flyout.
  - Armed `smooth`: keep the brush smooth strength/passes controls it had.
  - Nothing armed: show "Pick an operation."
  - Radius and shape are NOT in the sidebar; they float (D-19).

  - Builds a `div` with `role="radiogroup"` holding 32x32 `button` swatches.
  - Each swatch: `role="radio"`, `aria-checked`, `aria-label` and `data-tip` set to the surface name, background set to the surface's existing colour from the renderer's paint palette.
  - Layout: 4 columns, 4px gap.
  - Selecting a swatch calls `dispatcher.setOptions({ surface })`. This is the single shared value used by both the Terrain fill and the Terrain brush.
- History (D-21): the terrain `createShell` history stays `{ undo, redo, clearSelection }`. Do NOT add a `clearAll` key or any confirm dialog: the terrain editor never had Clear all. Only the map editor keeps its existing Clear all.
- View pad: remove the Grid and Contours `view.extra` buttons; they moved to the floating row (D-20). Keep Top-down. The View menu items may stay as aliases. Grid's key hint is X (UI-SPEC T superseded).
- The locked-road hover status (`updateLockHover`) stays. The cyan single-road "selected" overlay is removed in Task 2.
