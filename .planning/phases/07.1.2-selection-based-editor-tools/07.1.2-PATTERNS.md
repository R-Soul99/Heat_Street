## Pattern Assignments

### `src/core/terrain-cell-mask.ts` (NEW; model/utility, transform)

**Analog:** `src/core/terrain-overlay.ts` for the file header and core conventions, plus `dispatcher.windowBetween` (`tool-dispatch.ts` 518-537) for the input shape.

**Header and layering** (`terrain-overlay.ts` 1-14): pure core, no three/DOM, JSDoc explains conventions, flat typed arrays out.
```typescript
/** ... Layering: pure core, no three/rapier/DOM. */
import type { TerrainGrid } from "./terrain-grid.ts";
import type { CellWindow } from "./terrain-slope.ts";
```
`src/core` may not import from `tools/` (a layering test exists in `tests/layering.test.ts`), so the mask lives in core because `terrain-road.ts`/`terrain-graph.ts` need `cellAtXZ`.

**Input conversion** (`tool-dispatch.ts` 518-537): the existing drag box is a VERTEX window (inclusive) that is at least one cell and clipped. Convert once: cells `[minRow,maxRow) x [minCol,maxCol)`. Pitfall 4: never mix inclusive vertex and exclusive cell conventions.
```typescript
let minCol = Math.floor(Math.min(toCol(a.x), toCol(b.x)));
let maxCol = Math.ceil(Math.max(toCol(a.x), toCol(b.x)));
...
if (maxCol === minCol) maxCol += 1;
```

**Window clip helper to copy** (`terrain-overlay.ts` 29-37, `clipWindow`, requires `minRow < maxRow`: use this strict version for cell windows).

**Heights indexing to reuse for `vertexMask()`** (`terrain-brush.ts` 233, 260): `stride = grid.rows + 1`, index `r + c * stride`, output `Uint8Array(grid.heights.length)`. Same layout as `roadVertexMaskFromPaint` (`terrain-road.ts` 449-465) so masks can be OR-ed index by index.

**Outline segments:** emit flat `Float32Array [x0,y0,z0,x1,y1,z1,...]` like `gridLineSegments` (`terrain-overlay.ts` 44-74, local `put(r,c)` closure writing `originX + c*cell`, `heights[...] + lift`). The editor then drops it into a `THREE.LineSegments`.

### `src/core/terrain-brush.ts` (MOD; service, transform)

**Analog:** itself. Every mask op is a thin wrapper over `runHeightOp` (224-347). Do NOT add a second write path.

**Core wrapper pattern to copy: `setWindowFromBase`** (517-542):
```typescript
export function setWindowFromBase(grid, win, base, deltaM, rec?, opts?): BrushResult {
  if (!Number.isFinite(deltaM)) return noOp();
  const w = clipWindow(grid, win);
  if (!w) return noOp();
  const rowsN = w.maxRow - w.minRow + 1;
  if (base.length !== rowsN * (w.maxCol - w.minCol + 1)) return noOp();
  return runHeightOp(grid, w, (x, z, _h) => {
      const col = Math.round((x - grid.originX) / grid.cellSizeM) - w.minCol;
      const row = Math.round((z - grid.originZ) / grid.cellSizeM) - w.minRow;
      return base[row + col * rowsN] + deltaM;
    }, rec, false, opts);   // relax=false => hard step
}
```
`setMaskFromBase` = same, but `compute` returns `h` when `!sel[row + col*stride]` (research code example lines 360-376). `relax=false` gives the D-08 hard step; limiter still applies (D-24).

**Snapshot for hold-to-repeat** (`snapshotWindow`, 501-511): column-major `Float32Array`, taken once per hold.

**Smooth pass:** extend `smoothRegion` (551-...). The held-vertex branch to copy for "unselected = held":
```typescript
const mask = opts?.roadMask?.(win);
...
if (mask?.[row + col * stride]) { nxt[r + c * rowsN] = h; continue; }
```
Add `selected?: Uint8Array` and treat `!selected[idx]` identically. Params are clamped (`strength` 0..1, `passes` 1..`SMOOTH_PASSES_MAX`), non-finite is a no-op (`noOp()`); keep that rule for new inputs (Step, spacing).

**Flatten to average:** no mask analog; `flattenBrush` is disc-based. Compute the mean over `vertexMask()` before writing (D-28: include locked-road vertices in the average), then `runHeightOp(..., (x,z,h) => selected ? target : h, rec, false, opts)`. `runHeightOp` already returns `old[k]` for held vertices (line 262), so locked vertices stay put.

**Terrain fill:** copy `paintDisc`/`paintSurface` (740-775). The road-flag skip is the line to keep:
```typescript
return paintDisc(paint, params, rec, (old) =>
  (old & PAINT_ROAD_FLAG) !== 0 && opts.overRoads !== true ? old : value);
```
`paintMask` iterates pixel centres (`cx = paint.originX + (px + 0.5) * m`), tests `mask.cellAtXZ(cx, cz)`, calls `rec.beforePaintWrite(rect)` first (recorder 811-822).

**Removed code (D-17):** `BLOCK_CELLS_*`, `BLOCK_STEP_*`, `blockWindowAt` (433), `raiseBlock` (459), `stampTerrain`, `StampParams`. `raiseWindow` (477) can stay or be folded; check `tests/terrain-brush-window.test.ts` first (it covers block/stamp cases per research).

**Undo:** recorder in `createStrokeRecorder` (792-...): `beforeHeightsWrite`, `beforePaintWrite`, `recordGraph`, `recordLock`, `commit()` returns one `StrokeDiff`.

### `src/core/terrain-road.ts` (MOD; service, CRUD)

**Analog:** itself.

**D-23 fix, `roadVertexMask`** (518-542): add opt-in `padM = 0`. Existing signature and the two helper calls to pad:
```typescript
export function roadVertexMask(grid, paint, graph, area, free?: ReadonlySet<number>): Uint8Array {
  const mask = roadVertexMaskFromPaint(grid, paint, area);
  if (free === undefined || free.size === 0) {
    roadVertexMaskFromGraph(grid, graph, area, mask);      // pass padM here
    return mask;
  }
  const held = new Uint8Array(mask.length);
  roadVertexMaskFromGraph(grid, graph, area, held, (e) => !free.has(e.id));      // pass padM

```

### `src/core/terrain-graph.ts` (MOD; service, transform)

**Analog:** itself, `eraseGraphDisc` (853-928) and `refineAgainstDisc` (811-845).

Extract the splitter. Contract to keep: `refine(pts) => { pts: P3[]; keep: boolean[] }`. Existing disc refine pattern (new points via `lerp3`, guarded by `MERGE_EPS`, `keep[i]` from the segment midpoint):
```typescript
if (t * len > MERGE_EPS && (1 - t) * len > MERGE_EPS) out.push(lerp3(a, b, t));
...
keep.push(mx * mx + mz * mz > r * r);
```
Mask refine: insert points at `x = originX + k*cell` and `z = originZ + k*cell` crossings sorted by `t`, `keep[i] = !mask.cellAtXZ(midX, midZ)`. Rest of `eraseGraphDisc` is reused verbatim: runs of kept segments, first piece keeps `e.id`, later pieces `nextEdgeId++` and `splitFrom.push`, cut ends become `osmNodeId: 0` dead-end nodes, then `withJunctionFlags(nodes, edges, touched)` and `compactInternal`. Make `eraseGraphDisc` a thin caller so `tests/terrain-graph.test.ts` stays green.

## Shared Patterns

### One write path for height edits
**Source:** `src/core/terrain-brush.ts` `runHeightOp` (224-347) + `tools/terrain-editor/tool-dispatch.ts` `heightOpOptions` (191-198)
**Apply to:** every new height operation (raise, lower, flatten, smooth, push/pull, hold-repeat) and the D-23 fix. Holds locked-road vertices (line 252, 262), expands the dirty window, runs `limitSlope` with road vertices fixed (290-296, 337). Never write `grid.heights` directly.

### One undo step per user action
**Source:** `StrokeRecorder` (`terrain-brush.ts` 792-...) and `commitLockDiff` (`tool-dispatch.ts` 581-591)
**Apply to:** Delete road, Lock/Unlock, Terrain fill, hold-repeat Raise/Lower, Smooth hold. Pattern: `const rec = createStrokeRecorder(grid, paint)`, record via `beforeHeightsWrite`/`beforePaintWrite`/`recordGraph`/`recordLock`, `const diff = rec.commit(); if (diff) stack.push(diff);`. Selection changes are never pushed (D-07).

### Lock inheritance on graph edits
**Source:** `terrain-road.ts` `carryLock` (963-975) and `setRoadLock` (1329-1357)
**Apply to:** Delete road with cut; Lock/Unlock; save-guard messaging.

### Data-only tool lists with node tests
**Source:** `tools/terrain-editor/rail-tools.ts` + `rail-tools.test.ts`; `tools/map-editor/map-tools.ts` + `map-tools.test.ts`
**Apply to:** the new modes/operations/road tool lists, `toolbar-state.ts`, and the hotkey table. No DOM in these modules, vitest `environment: "node"`.

### DOM construction rules
**Source:** `tools/editor-shell/controls.ts` `el()` (13-24), `createButton` (26-36), `createStepper` (38-191), `createToggle` (213-229)
**Apply to:** all floating-toolbar, sidebar and Roads-section controls. All text via `textContent`; every control has `data-tip` (and `dataset.tipLong` where useful); buttons `type = "button"`; blur selects/checkboxes after change so letter hotkeys keep working (see `createSelect` 205-208).

### Numeric input hygiene
**Source:** `terrain-brush.ts` `sanitize`/`noOp` use and `smoothRegion` clamps (558-567); `PUSH_PULL_MAX_M` clamp in `pushPullTo` (923)
**Apply to:** Step, Grid spacing, Contour interval, mask bounds. Reject non-finite, clamp ranges, integers for spacing.

### Persisted preferences
**Source:** `tools/editor-shell/prefs.ts` (`PREFIX = "heat-street.editor."`, storage failures never throw, `setPrefStorage` test hook)
**Apply to:** per-mode option values (D-31). New keys need defaults; unknown or removed keys (`blockCells`, `blockStepM`, stamp options) must be ignored on read. Read `prefs.ts` fully in planning (only lines 1-30 were mapped). Memory note: saved browser tuning hides new code defaults.

### Layering
**Source:** `tests/layering.test.ts`; header comment "Layering: pure core, no three/rapier/DOM." in `terrain-brush.ts`/`terrain-overlay.ts`
**Apply to:** `terrain-cell-mask.ts` and any new `src/core` code: no imports from `tools/`, three, or DOM.
