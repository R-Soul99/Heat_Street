# Phase 07.1.2 — UI Design Contract

> Visual and interaction contract for the selection-based editor tools. Applies to the shared shell (`tools/editor-shell`), the terrain editor (full) and the map editor (shared conventions, D-22). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Source tags: [D-nn] = locked in 07.1.2-CONTEXT.md; [mockup] = `screenshots/ToolsLayout.png`; [07.1.1] = carried from the approved 07.1.1 UI-SPEC, unchanged; [Claude's choice] = gap filled by the researcher while the user was away (confirm in UAT).
> This spec only states what CHANGES. Anything not mentioned here keeps its 07.1.1 contract (sidebar width 240px, value box, tooltips, canvas offset, menubar, infobox, tokens).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla TS + DOM + hand-written `shell.css`; no UI framework per CLAUDE.md) |
| Preset | not applicable |
| Component library | none (shared shell controls: `createButton`, `createStepper` value box, tool rail) |
| Icon library | none. Unicode glyphs via `textContent`. New glyphs [Claude's choice]: Select ▭ (existing), Brush ◉, Terrain ◐ (existing Paint glyph), Unlock ⚿ with a trailing "open" variant ⚷ if available else ⚿ (label carries the meaning), Delete road ⌫, Square ■ / Circle ● toggle, Grid ▦, Contours ≈ is Smooth's glyph so Contours uses ◠ |
| Font | `13px system-ui, sans-serif` [07.1.1] |

Registry safety gate: not applicable (no shadcn, no third-party registries).

Tokens reused, no new colours: `--bg #14161a`, `--panel #1d2026`, `--panel-2 #262a32`, `--text #d8dde6`, `--accent #4aa3ff`, `--error #ff6b6b`, `--ok #66cc99`, `--warn #ffb347`; hairlines `#000`; destructive fill `#6b2b2b`.

**Focal point:** the large tool name at the top of the left sidebar, paired with the accent-highlighted mode button (Select or Brush) in the floating toolbar. The user always sees "which mode am I in, which operation is armed" before anything else [mockup].

### Terrain editor regions

| Region | Position | Contract |
|--------|----------|----------|

```
Row 1:  [ Select S ][ Brush B ] [ size box m ][ ■|● ]   [ Grid T ][ n cells ] [ Contours C ][ n m ]
Row 2:  [ Smooth G ][ Flatten F ][ Terrain P ]
Row 3:  [ ▲ Raise  H ]                 
        [ ▼ Lower  J ]                 
Row 4:  [ Paint R ]
```

- Row 1 chips: (a) mode chip: Select + Brush side by side [D-01]; (b) brush-size chip beside Brush: compact value box (Radius, same control as the old sidebar Radius, unit `m`) + Square/Circle two-state toggle [D-19]; (c) Grid chip: toggle button + value box; (d) Contours chip: toggle button + value box [D-20].
- Row 2 chip: Smooth, Flatten, Terrain [D-02, D-11].
- Row 3 chip: Raise over Lower, big [D-08, mockup]. Placed under row 2, left aligned with Row 1.
- Row 4 chip: road column, vertical, directly below Raise/Lower with 8px gap [D-14, mockup]. Order: Paint, Erase, divider (1px, full chip width), Lock, Unlock, Delete road. [Claude's choice: divider separates brushes from selection actions.]

Declared values (multiples of 4), unchanged from 07.1.1:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between buttons in a chip, chip padding, icon-to-label gap |
| sm | 8px | Gap between chips, sidebar padding, divider margins |
| md | 16px | Sidebar section separation, dialog padding |
| lg | 24px | Not used in this phase |
| xl | 32px | Value-box height, surface swatch size, Square/Circle toggle height |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Standard tool button: `height: 40px; min-width: 56px; padding: 0 8px` [07.1.1].
- Big Raise/Lower button: 64px wide x 40px tall each, glyph 24px, label to its right in the same chip (8px gap, label 16px/600); stacked 4px apart, so the pair is 84px tall. Label box width fixed 64px so the two rows align. [Claude's choice, proportions from mockup]
- Road column buttons share one width of 96px (fits "Delete road") so the column is a clean stack.
- Value boxes in the floating bar: 32px tall (xl), same anatomy as 07.1.1; Grid/Contours boxes sit 4px right of their toggle inside one chip, toggle height 32px to match the box.
- Square/Circle toggle: two 32px x 32px segments, 1px `#000` between, active segment accent.
- Surface swatch grid: swatches 32px x 32px, 4px gap, 4 columns (fits 240px sidebar minus 16px padding).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg #14161a` | Canvas surround, value-box fill |
| Secondary (30%) | `--panel #1d2026` / `--panel-2 #262a32` | Sidebar, floating chips, history/view pads (`--panel`); button faces (`--panel-2`) |
| Accent (10%) | `--accent #4aa3ff` | See reserved list |
| Destructive | `#6b2b2b` fill, `--error #ff6b6b` text | Clear all and Delete road only |

Accent reserved for:
1. The active mode button (Select or Brush; exactly one at a time).
2. The armed brush operation in Brush mode (Raise, Lower, Smooth, Flatten, Terrain, Paint or Erase, exactly one) and the momentary 150ms pressed flash of an operation fired in Select mode.
3. A Grid or Contours toggle in the on state; the active Square/Circle segment.
4. The selection overlay on the canvas: outline 2px accent, fill `rgba(74,163,255,0.25)` in Select mode; faint form in Brush mode (see Selection visuals).
5. The selected surface swatch (2px outline, offset 1px).
6. Keyboard focus ring (2px outline, offset 1px) on every control; value box border on focus or scrub [07.1.1].
7. Shortcut `kbd` text in the shortcuts dialog [07.1.1].

Not accent: dividers, sidebar border, tooltips, hover (`filter: brightness(1.15)` [07.1.1]), the sidebar tool name, Clear selection (neutral `--panel-2`).

Modifier rubber-band previews while dragging a box (canvas overlay only) [Claude's choice]:
- plain drag (replace): solid accent outline.
- Shift+drag (add): dashed accent outline, accent fill 0.25.
- Ctrl+drag (subtract): dashed `--warn` outline, `rgba(255,179,71,0.2)` fill.

Destructive note [Claude's choice]: the mockup shows Clear selection in red; this spec keeps it neutral because it is non-destructive (selection is not an undo step, D-07). Clear all keeps its red fill.

## Component Contracts

### 1. Mode buttons: Select and Brush [D-01, D-02, D-03, D-06]
- Standard tool button anatomy (glyph over word, key hint top-right 11px). Labels "Select" (S) and "Brush" (B).
- Exactly one is active (`aria-pressed="true"`, accent). Initial mode on load: Select, no operation armed. Mode persists for the session; remembered per browser with the other options [D-31].
- Switching mode keeps the selection mask [D-06]; it never clears it.

### 2. Operation buttons [D-02, D-03, D-08..D-11]
Raise, Lower, Smooth, Flatten, Terrain (Paint and Erase are road brushes, see 4).

| Mode | Click behaviour | Visual state |
|------|-----------------|--------------|
| Brush | Arms that operation as the brush; stays armed until another is chosen; drag on terrain applies under cursor | Armed button accent, stays |
| Select, selection exists | Applies immediately to the selection (Raise/Lower: one Step; Smooth: one pass; Flatten: level to average; Terrain: fill with the current surface) | Normal face; 150ms accent flash on activation; no persistent highlight |
| Select, no selection | Does nothing; status line says "Select an area first (drag on the map)" | Disabled look (opacity 0.4, `aria-disabled`, still hoverable for tooltip) |

- Raise/Lower hold-to-repeat: pointer-down fires once, then after 400ms repeats every 120ms until pointer-up, blur or selection loss; each repeat is one Step. A whole press-hold-release sequence is ONE undo step [Claude's choice: undo granularity so Undo does not need 40 presses]. Hotkeys H/J use the same repeat timer; the OS key-repeat (`e.repeat`) is ignored in favour of it.
- Smooth in Select mode repeats the same way (one pass per tick, one undo step per hold) [D-10].
- Hard step is clamped by the slope limiter; the existing status message shows when clamped [D-24].
- Big Raise/Lower: see Spacing exceptions. Glyph 24px ▲ / ▼, label "Raise" / "Lower" 16px/600 to the right inside the chip, key hint 11px at the top-right of each button. Same active / hover / focus / disabled states as any tool button.

### 3. Brush size and shape chip [D-19]
- Value box: Radius, unit `m`, same spec as the old sidebar Radius (min/max/step from existing options), tooltip "Brush size (drag, scroll or use arrows; Shift = coarse)".
- Square/Circle two-segment toggle, `role="group"`, segments `aria-pressed`, glyphs ■ / ●, labels via `aria-label` "Square" / "Circle"; maps to existing `brushShape`.
- Disabled in Select mode (opacity 0.4).

### 4. Road column [D-14, D-15, D-16, D-25, D-26]

| Button | Key | Type | Enabled when |
|--------|-----|------|--------------|
| Paint | R | Road brush. Click arms it: switches to Brush mode and arms Paint (accent on Brush AND on Paint) | Always |
| Erase | E | Road eraser brush, same arming behaviour | Always |
| Lock | L | Selection action: locks whole road edges touching the selection (no split) | Select mode with a selection |
| Unlock | U | Selection action: unlocks whole road edges touching the selection | Select mode with a selection |
| Delete road | Del | Selection action: removes road inside the selection, cutting at the selection edge; locked roads too; one undo step. Fill `#6b2b2b` | Select mode with a selection |

In Brush mode with a selection present, Lock / Unlock / Delete road are disabled (selection is faint, not live) with tooltip "Switch to Select mode (S) to use this" [Claude's choice]. Hotkeys for them do nothing then and show the same hint in the status line. No confirmation on Delete road (undoable) [D-07, D-15].

### 5. Grid and Contours chips [D-20, D-31]
- Toggle button (glyph + word, 40px, standard button states, `aria-pressed`) plus adjacent value box, visible in both modes and in the map editor (Grid only there).
- Grid value (terrain): line spacing in cells; value box steps through presets 1, 2, 5, 10, 20, 50 [Claude's choice]; typed values snap to the nearest preset; unit `cells`. Display only; the terrain cell size is not changed. Map editor: spacing in metres, presets 1, 5, 10, 20, 50, 100, unit `m`.
- Contours value: the existing contour interval (existing min/max/step), unit `m`. The old interval dialog becomes redundant; the planner may keep its menu entry or drop it.
- Hotkeys: C Contours, T Grid [Claude's choice for the Grid key; planner must confirm T is free in both editors' hotkey tables].

### 6. Selection visuals [D-04, D-06] [Claude's choice for all drawing details]
- Select mode: selected cells filled `rgba(74,163,255,0.25)`; outline drawn along the mask boundary only (not around every cell), 2px accent; L-shapes and holes follow the mask boundary.
- Brush mode (faint): fill `rgba(74,163,255,0.10)`, outline 1px at 50% accent alpha.
- Rubber-band preview while dragging per modifier (Color section).
- Cursor: crosshair over the terrain in Select mode; `ns-resize` while Alt-dragging for push/pull [D-05]; Shift/Ctrl add `+`/`-` hint only via the status line ("Shift: add, Ctrl: subtract, Alt: push/pull").
- Esc clears the selection; so does Clear selection [D-06]. Alt keydown/keyup default (browser menu bar) is prevented while the editor canvas or body holds focus and no text field is focused [D-05].

### 7. Left sidebar content [D-12, D-18, D-24, D-27]
Structure: tool name (Display 24px/600) -> subtitle (13px, opacity 0.7) -> 1px divider -> options body. Option rows follow 07.1.1 (label above control, 8px between, full-width buttons).

| State | Tool name | Subtitle | Options body (top to bottom) |
|-------|-----------|----------|------------------------------|
| Select mode | "Select" | selection readout: "No selection" or "{n} cells, {area} m2" | Hint block (modifiers, muted 11px). Step (value box, m per click). Strength (smooth pass strength; label "Smooth strength"). Slope limit (deg). Surface picker (swatch grid, label "Surface"). Readouts: Selection size, Average height. `details.section` "Roads" (open by default): Re-grade selection, Re-grade all unlocked, Lock all, Unlock all, locked/unlocked counts |
| Brush mode, op armed | "Brush" | armed op name, e.g. "Raise" | Strength, Falloff (select), Slope limit; Surface picker only when Terrain is armed. Radius and shape are NOT here (floating, D-19) |
| Brush mode, no op armed | "Brush" | "Pick an operation" | Strength, Falloff, Slope limit |
| Map editor | active tool label (e.g. "Draw road") | none | existing per-tool options; Select shows hint block |

- Step and Smooth strength (Select) and Radius, Strength, Falloff (Brush) are separate remembered values [D-12]; the two Strength fields are distinct controls with distinct labels.
- Surface picker: swatch grid, each swatch 32px with the surface's existing colour, name as `data-tip` and `aria-label`, selected swatch has the accent outline; one shared selection for both modes [D-11]. Names follow the existing surface list (tarmac, gravel, grass, and the rest).
- Slope limit is visible in both modes because hard steps obey it [D-24].
- Roads section buttons are full-width. The counts row reads "{n} roads: {a} locked, {b} unlocked" (same wording as the infobox). The Roads section is hidden in Brush mode [D-27 "visible in Select mode"].

### 8. History pad [D-21]
Undo, Redo, 1px divider (24px tall), Clear selection (neutral, disabled when no selection), Clear all (danger, unchanged meaning and confirmation).

### 9. Map editor selection [D-22]
- Select tool drag draws a box; Shift+drag adds, Ctrl+drag subtracts; boxes select roads and features whose geometry the box touches [Claude's choice: "touches", not "fully inside", the easier hit]. Selected items render with an accent highlight; box rubber-band as in Color.
- Delete key removes the selection; one undo step; no confirm. Esc clears.

## Interaction and State Contract

| Situation | Behaviour |
|-----------|-----------|
| Load | Terrain: Select mode, no selection, no op armed. Sidebar shows Select options |
| Switch Select -> Brush | Selection kept, drawn faint; sidebar swaps to Brush options; Radius/shape controls enable; selection-action buttons (Lock, Unlock, Delete road) disable |
| Switch Brush -> Select | Selection live again; armed op remembered but not shown as active; brush controls disable |
| Click Paint/Erase in Select mode | Switch to Brush mode and arm it |
| Op button in Select mode, no selection | Nothing happens; status "Select an area first (drag on the map)" |
| Esc | Clears selection (terrain and map). If a dialog or text field has focus, Esc keeps its current meaning |
| Typing in a value box | Letter hotkeys suspended (existing `isTextEntryFocused`) [07.1.1] |
| Operation blocked by locked-road ring (D-13, D-23, D-30) | Op runs on the free cells; status line notes "Cells beside locked roads were left untouched" [Claude's choice] when any selected or brushed cell was held |
| Slope clamp | Existing clamp message [D-24] |
| Alt held on canvas | Browser menu activation prevented; push/pull drag available |
| Narrow window (< ~900px) | Floating chips wrap; sidebar fixed; no horizontal scroll |

Hotkeys (listed in the shortcuts dialog and on button key hints; the hotkey test keys on `e.code`) [D-29]:

| Key | Action | Key | Action |
|-----|--------|-----|--------|
| S | Select mode | R | Road Paint |
| B | Brush mode | E | Road Erase |
| H | Raise | L | Lock |
| J | Lower | U | Unlock |
| G | Smooth | Delete | Delete road (map editor: delete selection) |
| F | Flatten | C | Contours toggle |
| P | Terrain | T | Grid toggle |
| Esc | Clear selection | | |

Map editor keeps V, M, R, B, E for its tools and adds T (Grid), Delete (remove selection) and Esc.

Accessibility: every button keeps `aria-label` (long name) and `aria-pressed` where toggle-like; disabled operation buttons use `aria-disabled="true"` so tooltips still explain why; swatches are a `role="radiogroup"` with `role="radio"` children; toggles Square/Circle `role="group"`; chips are `role="toolbar"` with `aria-label`; focus rings visible; all DOM text via `textContent`; every control has `data-tip`.

## Deviations (post-checker, 2026-11-14)

Recorded during planning; these supersede the matching lines above and are listed in HUMAN-UAT for the user to confirm.

1. **Grid hotkey is X, not T.** T is already the terrain editor's Top-down key (`BINDINGS` `topdown` / `KeyT`). X was already the terrain grid key and is free in the map editor, so Grid uses X in both editors.
2. **The terrain editor has no Clear all.** It never had one; D-21 for terrain means the history pad is Undo, Redo, Clear selection. The map editor keeps its existing Clear all beside the new Clear selection. Section 8 and the Layout Contract history-pad row apply as "Clear all only where it already exists (map editor)".
3. **Map box-select uses touches semantics.** A box selects every road and feature its geometry touches; a Ctrl+drag subtract box removes any item it touches as a whole (no road cutting in the map editor).
