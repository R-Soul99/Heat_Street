# Phase 07.1.2 Plan 09: Map editor conventions Summary

Map editor now uses floating tool/grid/terrain chips, a metre-spaced grid toggle (X), and Shift-add / Ctrl-subtract box selection with Delete (one undo) and Esc clear.

## Commits
- f3f3afe: pure `selectionFromBoxes`, tool codes + `MAP_GRID_TOGGLE`, `gridMinorStep` with tests (Task 1)
- db216fa: editor wiring (Tasks 2 and 3 combined, both only touch editor.ts)

## What changed
- Floating row: Tools chip, Grid chip (toggle + spacing stepper, presets 1/5/10/20/50/100 m), Terrain chip. Bottom toolbar lookup removed; scale bar starts at the default left pad.
- Grid toggle removed from view pad extras; View menu item kept. `drawGrid` uses `gridMinorStep(gridSpacingM, scale)`, major = 5x minor.
- History pad: Clear selection beside Clear all, enabled state follows the selection.
- `boxRect` replaced by `boxes[]`; live rubber band is solid accent (replace), dashed accent with 0.25 fill (add), dashed warn orange (subtract). A subtract that empties the selection clears the boxes.
- Esc clears the selection after cancelling any drawing. Select-tool sidebar shows the add/subtract hint; status hint includes "Shift: add, Ctrl: subtract".

## Deviations from Plan
None of substance. Tasks 2 and 3 were committed together since both edit only editor.ts. Committed boxes are not drawn individually (selected items keep their highlight), per plan.
