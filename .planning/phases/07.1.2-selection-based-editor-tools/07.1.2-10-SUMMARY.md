# Phase 07.1.2 Plan 10: Terrain editor floating toolbar integration Summary

The terrain editor now shows the mockup floating toolbar and routes every click and hotkey through one `routeToolbar`/`runToolbarAction` path, with hold-repeat, mask selection visuals, modifier rubber bands and Alt+drag push/pull.

## What was built

- FLOAT_ROWS: modes, brush size + Square/Circle, Grid + spacing, Contours + interval; Smooth/Flatten/Terrain; big Raise/Lower; road column (Paint, Erase, Lock, Unlock, Delete road). Slots built with `createStepper`/`el` (textContent only).
- `syncToolbar` applies `toolbarState` (pressed, enabled, disabled tips, sidebar title, Clear selection enabled, brush chip dimmed to 0.4 in Select mode). The editor's legacy `tool` is now derived from dispatcher mode/armed (`syncToolFromDispatcher`).
- Hold repeat via `createRepeater` + `beginOpRepeat/opRepeatTick/endOpRepeat`; stops on pointerup/leave/cancel/lostpointercapture, blur, Esc, area load and empty selection. The click after a pointer hold is suppressed so no double apply.
- Selection: `LineSegments` from `boundarySegments` plus a fill mesh from `fillTriangles` (skipped above 250k cells); Select 0.25/1.0, Brush 0.10/0.5. Rubber bands: replace solid accent, add dashed accent, subtract dashed orange.
- Alt+drag starts push/pull in Select mode with a selection; Alt keydown/keyup default prevented (not in text fields/dialogs). Cursor crosshair/ns-resize.
- Hotkeys via `TERRAIN_HOTKEYS[e.code]` (non-repeat); X/C removed from BINDINGS (T Top-down and D Drive kept). Esc cancels hold, push/pull or drag first, otherwise clears the selection.
- Grid spacing flows into `footprintGridSegments`/`gridLineSegments` and the cache key; in Select mode with a selection the grid covers the selection bounds (assumption A4, for UAT). Contour stepper shares state with the View menu dialog.

## Deviations

- **[Rule 3 - Blocking] `cancelBoxDrag` extended** (tool-dispatch.ts): it now also drops a `gridSelect` drag, so Esc can abandon a rubber-band without the old snapshot/`setSelection` round trip (which would flatten a non-rectangular mask). Test added.
- Three tasks landed in one commit (ff76901) because all edits are in editor.ts and interleaved.
- Esc is staged: it cancels an active hold/push-pull/drag first and clears the selection on the next press (rather than both at once).
- Remaining `THREE.LineLoop` uses are unrelated to the selection: cursor ring, block outline, smooth-box/rubber-band `boxOutline`, road-problem highlight. `windowPerimeter` remains only for the rubber band.
- Old tools (block, stamp, smoothBox, lock) are no longer reachable from the toolbar or keys; their flyout code is left for plan 11. Select-mode status hint is set when switching into Select, not persistently.
