  - `FloatItem = { kind: "tool"; tool: ShellTool; size?: "big" } | { kind: "divider" } | { kind: "slot"; id: string }`
  - `FloatChip { id: string; label: string; direction: "row" | "column"; items: FloatItem[] }`
  - `FloatRow = FloatChip[]`
- `validateFloatSpec(rows: FloatRow[]): string[]` (pure).
- `createFloatingToolbar(rows, slots: Record<string, HTMLElement>, onClick: (id: string) => void): FloatingToolbar`, where `FloatingToolbar { el: HTMLElement; button(id): HTMLButtonElement | undefined; setPressed(id, on); setEnabled(id, on, disabledTip?); flash(id) }`.
  - Container is `div.shell-floatbar` (`pointer-events: none` in CSS). Each row is `div.float-row`. Each chip is `div.float-chip` with `role="toolbar"`, `aria-label` set to chip.label, and class `col` when its direction is column. A chip's `pointerdown` calls `stopPropagation()` (UI-SPEC Canvas rules).
  - Tool buttons copy the tool-rail factory:
    - `el("button", "tool-btn", undefined, keyLabel ? `${tip} (${keyLabel})` : tip)` with `type="button"` and `aria-pressed="false"`
    - `aria-label` = `${displayLabel(t)} (${keyLabel})`, plus `dataset.tipLong`
    - children are a glyph span `.tool-glyph`, a word span `.tool-word` (displayLabel) and a key-hint span `.tool-key`, all set via `textContent`
    - `size: "big"` adds class `big` (glyph 24px, label 16px/600 to the right; UI-SPEC Spacing exceptions)
  - Disabled state per UI-SPEC: `setEnabled(id, false, tip)` sets `aria-disabled="true"`, adds class `is-disabled` (opacity 0.4) and swaps `data-tip` to the disabled tip. It does NOT set `.disabled`, so tooltips still show and `onClick` still fires; the editor reports the blocked status. `setEnabled(id, true)` restores the original tip.
  - `flash(id)` adds class `flash` for 150 ms (accent flash for Select-mode operations).
  - Dividers are `div.float-divider`: 1px, full chip width in a column, full height in a row.
- In `tool-rail.ts`, add optional `code?: string` to `ShellTool`. Keep `dock?` and `group?` for now, marked `@deprecated`; plan 11 removes them.
- Move `displayLabel` into `tool-rail.ts` and export it. `tool-groups.ts` imports it from there and re-exports it, so existing imports keep compiling.

- Copy the displayLabel test cases into `floating-toolbar.test.ts`.
- Do NOT delete anything in this task. `shell.ts` still uses `createToolRail`, `dock.ts` and `tool-groups.ts` until Task 2 switches it, which keeps `tsc` green.
