# Phase 07.1.2 Plan 08: Dispatcher road actions + save-guard message Summary

Selection-based Lock, Unlock, Delete road and Re-grade selection on the dispatcher, each a single undo step, with held-cells and stale-road messages pointing at controls that exist.

## Tasks

1. `applyRoadAction(lock|unlock|deleteRoad)` and `regradeSelection()` (commit 92c5bae). Lock/unlock use `edgeIdsInMask` + `setRoadLock` (whole edges, no split); delete uses `eraseRoadRegion` (works on locked roads). Guards: Brush mode returns the switch-to-Select status, no selection returns `NO_SELECTION_MSG`, no roads returns "No roads in the selection". `heldStatus` and the editor.ts literal now say "Select the road and press Unlock (U)". New tests cover all behaviors.
2. Save-guard message now says "Select an area, then use Roads in the sidebar (...)" (commit d8ace3e); test updated to substring checks.
