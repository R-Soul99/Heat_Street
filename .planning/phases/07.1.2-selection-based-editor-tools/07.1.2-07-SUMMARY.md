# Phase 07.1.2 Plan 07: Dispatcher modes, selection and operations Summary

The terrain dispatcher now has a select/brush mode, a persistent CellMask selection (plain drag replaces, Shift adds, Ctrl subtracts), Alt+drag push/pull, selection operations (raise/lower/smooth/flatten/terrain) and hold-to-repeat sessions that commit one undo entry per hold. All height calls go through `heightOpOptions(area, options)`, so locked roads never move.

## Deviations from Plan

- Both tasks were committed together (single commit 3695ca0) because they edit the same files and the second builds directly on the first; work was done in task order.
- Old `raiseSelection` status text changed to the shared `NO_SELECTION_STATUS` ("Select an area first (drag on the map)"); the existing test was updated accordingly.
- Default `getTool()` returns "raise" when brush mode has nothing armed (legacy accessor, removed in plan 11).
