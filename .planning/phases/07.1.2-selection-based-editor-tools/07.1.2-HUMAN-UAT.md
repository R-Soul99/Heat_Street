# Phase 07.1.2 Human UAT: selection-based editor tools

Everything a computer test cannot see: layout, mouse feel, timing, browser quirks. All the automated tests (2354) already pass. While you were away I made some choices for you; section 10 and 11 list them so you can keep or change each one.

## How to open

1. In a terminal in the project folder run `npm run dev`. It prints a local address (usually http://localhost:5173).
2. Terrain editor: that address plus `/tools/terrain-editor/index.html`
3. Map editor: that address plus `/tools/map-editor/index.html`
4. Heads-up: the editors remember settings in the browser. If a value looks stale or a new default seems missing, clear site data for localhost (browser settings, or F12 > Application > Clear site data) and reload.
