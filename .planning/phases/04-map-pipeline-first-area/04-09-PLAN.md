<interfaces>
The Phase 3 render contract this must reproduce, from `src/render/surface-view.ts`:

```typescript
export interface SurfaceWorldView {
  group: THREE.Group;
  zoneMeshes: THREE.Mesh[];      // parallel with SURFACE_ZONE_ORDER
  buildingMeshes: THREE.Mesh[];  // consumed by createOcclusionProbe / createOcclusionController
}
```

`createSurfaceFx(zoneMeshes: readonly THREE.Mesh[], zoneSurfaces: readonly SurfaceType[])` takes
those two as PARALLEL arrays and builds a `SurfaceType -> Mesh` map for skid-decal projection.
`MapWorldView` must therefore expose `roadMeshes` and `roadSurfaces` as parallel arrays in the
same shape — which is exactly why plan 04-07 split the `.glb`'s road geometry into one mesh per
surface named `roads-<surface>`.

`createOcclusionProbe(buildingMeshes)` and
`createOcclusionController(probe, buildingMeshes, rig, tuning, "fade")` both take the building
mesh list; `docs/adr/0003-occlusion-mitigation.md` records that fade ships and that steepen is
blocked by a known fan-ray bug.

`GLTFLoader` from `three/addons/loaders/GLTFLoader.js` — this is the project's first use of it.
Import via the `three/addons/...` alias, never `three/examples/jsm/...`.
</interfaces>

<plan_decisions>
- **D-P25 — `src/main.ts` becomes top-level `await`.** The map is fetched and the `.glb` loaded
  before the scene can be built. Vite's `build.target: "esnext"` supports top-level await; the
  existing synchronous boot is replaced rather than wrapped in a floating promise, because a
  floating promise here would race `startLoop` against an unloaded world.
- **D-P26 — `src/physics/surface-scene.ts` and `src/render/surface-view.ts` are NOT deleted.**
  They become regression fixtures exactly as `vehicle-scene.ts` and `debug-scene.ts` did when
  Phase 3 superseded Phase 2 — `tests/` imports them and `surface-scene.ts` carries its own
  explicit do-not-delete note. Deleting them is a separately planned task, never a side effect.
- **D-P27 — a load failure renders a named message into the page, not a blank canvas.** A missing,
  stale or malformed artifact is the single most likely failure a developer will hit here, and a
  black screen gives them nothing to work with.
</plan_decisions>
