    Functions and definitions (research "Headless measurement helpers"):
    - `measureZeroToSixty(tuning, opts?)`: the accel routine from `ROUTINES.find(r => r.id === "accel")` via `runRoutine`, forwarding surface opts as `SurfaceRunOpts` when `opts.surface` is set and `opts` as the fifth argument; returns seconds (+Infinity if never reached).

    - `measureSettle(tuning, opts?)`: zero input for 600 ticks; reference = chassis y at tick 300; settleSec = (first tick after which y stays within 0.01 m of the reference to the end) times DT; also return bandM = max |y - ref| over ticks 300-599. Returns `{ settleSec, bandM }`.

    - `measureSurfaceSkidpad(tuning, surface, profiles, opts?)`: the skidpad routine via runRoutine with `{ surface, profiles }`; returns `.value` (g).
