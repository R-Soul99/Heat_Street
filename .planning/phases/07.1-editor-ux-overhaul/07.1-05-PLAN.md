<objective>
Implement the D-07 map-editor tool set on the shell: box Select with Roads/Buildings/Objects tickboxes and Delete/Disable, simplified Draw road options, Eraser, Clear all with confirm, and [ ] value keys (D-09). Undo/Redo already exist from 07.1-03.

Purpose: the user's requested editing workflow, kept to small pure helpers plus thin canvas wiring.
Output: selection.ts (+tests, including a compiler-level proof that disabled roads are skipped) and editor.ts wiring.

Disable decision (resolves research Open Question 1, verified by the planner in code): the compiler drops any road way without a `highway` tag (tools/map-compiler/graph/build-graph.ts lines 366-368, counted as "no-highway-tag"), so disabling a road renames `highway` to `disused:highway` (reversible, OSM convention). Buildings have NO such skip: every building way compiles (building-box.ts defaults a missing building tag to "yes"), and changing the compiler is out of scope for this phase. So Disable applies to ROADS ONLY; for buildings the Select flyout offers Delete only and says why in the tooltip. Flagged to the user as an open decision.
</objective>
