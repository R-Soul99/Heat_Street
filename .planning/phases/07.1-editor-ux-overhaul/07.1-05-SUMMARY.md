# Phase 07.1 Plan 05: Map Editor Tool Set Summary

Box Select with Roads/Buildings/Objects tickboxes (Delete, Disable, Enable), grey-dashed disabled roads, Eraser, simplified Draw road options, Clear all with confirm, and E / [ ] shortcuts.

## Commits
- fb4f057 feat(07.1-05): pure helpers (tests written and seen failing first; 6 tests)
- Second commit (see `git log`): editor.ts wiring

## What changed
- selection.ts (pure): Box, normaliseBox, segmentIntersectsRect (Liang-Barsky), waysInBox, buildingsInBox (centroid), isRoadDisabled, setRoadDisabled, applyBoxAction.
- Compiler proof: test runs buildGraph on two connected roads; with one disabled the edge count equals the single-road case. Compiler untouched.
- Select: left-drag over 4 px draws a dashed cyan box; flyout shows counts, tickboxes (Objects disabled with tip), Delete ticked / Disable roads / Enable roads / Clear box. Plain click still picks one item. Panning on Select is now right/middle drag, pan pad, arrows. Delete/Backspace act on the box when present. Esc clears it. Single-pick editor has Disable road / Enable road.
- Disabled roads draw grey (#666) dashed, underneath enabled roads.
- Eraser (E): click/drag deletes under the cursor, one snapshot on first hit per drag, cursor circle shown.
- Draw road flyout: Width and Surface up front, Highway under a collapsed "More".
- Clear all (top right) confirms, then empties both envelopes as one undo step.
- `[` / `]`: road width +-0.5 (Shift 2), building height +-1 (Shift 5); other tools say there is no adjustable value.

## Deviations from Plan
- Minor: first attempt at the compiler test used two disconnected roads and the compiler's largest-component prune dropped one; the test now joins them at a shared node. No production change.
- Open decision for the user (as the plan flagged): buildings cannot be disabled because the compiler has no skip for them.
