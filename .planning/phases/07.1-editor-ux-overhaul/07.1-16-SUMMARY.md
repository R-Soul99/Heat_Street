# Phase 07.1 Plan 16: Start screen and Open in terrain editor Summary

The 2D map editor opens on a start screen (nothing auto-loads) and a prominent "Open in terrain editor" action saves, compiles, converts to the terrain format, registers the map as "terrain" and opens the terrain editor on it.

## What changed
- Start screen: New map, Import image, Open existing map (list), Close. File > Start screen brings it back. Editing is inert until a map is open.
- Open in terrain editor (File menu + button next to Undo/Redo): confirm dialog if a terrain version exists (open existing vs replace), road check, save, POST /__editor/to-terrain/<id>, result dialog, then navigate to terrain-editor?area=<id>.
- Messages name paths: drawing in tools/map-compiler/areas/<id>.*, playable map in public/maps/<id>.*, terrain in public/maps/<id>.terrain.*.
- Convert for authored ids: authoredConvertConfig (3 m cells up to ~2 km square = ~445k vertices, coarser above; paint 0.5 m/px within 16M pixels; roadWidenM 2; buildings per map). Built-in CONVERT_CONFIG untouched. Id matched exactly against the manifest.
- A terrain-format map is briefly flipped to legacy for a recompile and restored (compileArea), so Save & compile keeps working after conversion.
- fixFoldedRoads removed (import + compile); Check roads only reports.
- Box select: Select tip, info-bar hint and start screen explain drag-a-box then Delete; flyout laid out as a clean column.
- Terrain editor: ?area=<id> exact match opens that map.

## Verification
Full suite 2152 passed; tsc clean; biome clean on changed files.
