## Tests

### 1. Terrain editor - Shift+[ ] and tooltip placement
expected: ] / [ change brush size by a small step, Shift+] / Shift+[ by a big step. Tooltips on the bottom tools (M, S, L) open on a free side and never cover other buttons. Layout otherwise unchanged.
result: pass

### 2. Stamp footprint and rotation
expected: With the Stamp tool, the cursor shows the real rotated stamp outline with a yellow rise arrow (not a circle). [ / ] rotate it in small steps, Shift+[ / Shift+] rotate it by 45 degrees, and the outline turns on screen to match.
result: pass

### 3. Slope limit setting
expected: Raise, Lower, Smooth, Flatten, Stamp, Block, Grid select and Smooth box flyouts each have a "Slope limit" stepper, default 35. Raising it (e.g. to 60) lets Raise build a visibly steeper hill; when the clamp kicks in, the status names the current limit, not always 35.
result: pass

### 4. Locked / unlocked road indication
expected: On a map with roads, unlocked roads draw as dashed orange lines and locked roads as solid. The Lock flyout shows a colour key. The info box reads "N roads: L locked, U unlocked". Hovering a road with the Lock tool shows "Road N is LOCKED" or "Road N is UNLOCKED" in the status line.
result: pass

### 5. Road problems panel - wording, badges, save
expected: Open new-area-2 (the open looped path from round 1). View > Road problems shows the header "Road problems: N (B block saving)". Each row names the road and its end (e.g. "The end of Road 1 ..."), one row per cut-off piece, with a grey "warning" badge (red "blocks saving" only for real corruption). Save works without the panel popping up; the log has one info line saying saving still works.
result: pass

### 6. Road problems panel - fix buttons
expected: Rows show one button per fix (Make two-way, Connect ends, Close loop, and the older Remove duplicate points / Smooth / Re-grade where relevant). Clicking one fixes the road, the status says what it did (e.g. "Closed the loop on Road 1."), the row disappears, and one Ctrl+Z undoes the whole fix exactly. If nothing is in range, the status explains why (e.g. "nothing within 250 m ... draw a road to it by hand").
result: pass

### 7. Terrain editor - bad ?area link
expected: Open /tools/terrain-editor/index.html?area=does-not-exist. A "Could not open does-not-exist" dialog appears explaining there is no saved terrain map by that name, with "Back to map editor" (goes to the map editor) and "Stay here" buttons.
result: pass

### 8. Map editor - New popup errors and start screen
expected: In the map editor File > New popup, enter an invalid value (e.g. size below 0.5 km) to show an inline error, then correct it: the error disappears as soon as you edit. Create the map: the start screen closes and does not come back.
result: pass

### 9. Map editor - blank map is visible
expected: A newly created 0.5 x 0.5 km blank map shows a clearly visible lighter square with a bright border, and centred text "Empty map 0.5 x 0.5 km. Press R to draw a road." It is not a black screen.
result: pass

### 10. Map editor - dock layout
expected: Map editor matches the terrain editor dock: info box bottom-right, history pad and view pad top-right with Grid / Tiles / Legend toggle buttons that show a pressed state (and stay in step with the View menu ticks), legend under the view pad, five tools as a button row bottom-left with the flyout above the active tool, "Open in terrain editor" top-left. Nothing overlaps; tool tooltips don't cover other buttons; scale bar visible to the right of the tool row.
result: pass
notes: "History pad" = Undo / Redo / Clear all buttons top-right; present.

### 11. Map editor - Open in terrain editor
expected: (a) On the blank map with no roads, Open in terrain editor shows a dialog "Draw a road first" and stays in the map editor. (b) On popp-roads, it saves/converts, and only after the terrain map exists does it land in the terrain editor with popp-roads loaded (not the start screen). (c) Any failure shows a "Could not open in terrain editor" dialog with the reason. Known limit: tiny/sparse road networks (one road, or a "+" of two) fail conversion at the route step; that should show the dialog with the compiler's error, not silently fail.
result: pass

### 12. Map editor - reload resumes the map
expected: With a map open in the map editor, press F5 (or let the dev server restart). The editor reopens the same map instead of the start screen.
result: pass
