# Phase 07.1 Plan 07: Terrain editor on the shared shell Summary

The terrain editor now uses the same shell as the map editor (no scrolling sidebar), with Raise (H) and Lower (J) as separate modifier-free tools, a Block direction toggle instead of Alt, brush options in per-tool flyouts with steppers, and a New popup that validates inline.

This is a small deviation from the task split, not from behaviour.

## Where each old feature lives now

- Tools (rail, all ids = dispatcher Tool ids): Raise H, Lower J, Smooth G, Flatten F, Surface paint P, Road brush R, Stamp W, Erase road E, Block B, Smooth area A, Lock/unlock road L, Grid select V (hint only; selection outline, step buttons and Ctrl push/pull are 07.1-08).
- Flyouts: radius/strength/falloff (+surface for paint); road: surface, class, width, bank max (flyout rebuilt on class change so the bank max follows the preset); block: direction pair, size with "N x N (M m)" readout, step; smooth area: strength, passes, Smooth whole map; lock: radius, Lock all, Unlock all, Re-grade selected, Re-grade all unlocked, colour legend text; stamp: kind, height, width, rotation readout.
- Lock overlay (grey/orange/cyan), both save guards (saveBlockMessage, staleRoadBlockMessage), CR-01 editCounter/saving, Drive here, grid/contour overlays, middle-drag tilt/spin, right-drag orbit, Shift+right-drag and Ctrl+wheel pan: code kept as it was, only status/log/DOM glue changed.
- File menu: New..., Load selected, Save terrain (Ctrl+S), Drive here (D). View menu: Grid X, Contours C, contour intervals 0.25 to 10, Top-down T, Frame area. Help: shortcuts, Surface colours, Area details (vertices, chunks, last edit), Show log, tooltips toggle.
- Info bar: Area, Size, Cell, Cursor, Height, Slope, Surface, Nearest road, Brush, Tip, unsaved marker, status. Refusals (save guards, save/load/list failures, Drive here unregistered id, pop-up blocked) use error style and leave the dirty marker alone.
- View pad: zoom 0.8/1.25 dolly (clamped 5 .. far/2), Fit = frame area, pan 10 % of camera distance, extra "Top" button; arrow keys pan.
- Alt: no remaining use in editor.ts. Pointer events pass `{ctrl, shift}` only. Lock tool selects with Shift.

## Deviations from Plan

1. **[Minor] Brush info field.** The plan routes the block/smooth-box readout to the hint field; I gave it a separate "Brush" field so the zoom hint (HEIGHT_TOOLS) is not hidden while Block or Smooth area is active.
2. **[Minor] index.html keeps a small style block** (text-input styling for the New popup name field), as the map editor does, rather than being fully bare.
3. **[Minor] Extra user-facing messages.** Toolbar-style actions (Lock buttons, Fit, Top-down, Load with nothing saved) say so in the info bar when no area is loaded instead of silently doing nothing.
4. Task 2/3 split as noted above.

No Rule 1 to 3 fixes were needed. Existing tests were not modified; tests/terrain-editor-status.test.ts passes unchanged (no innerHTML anywhere in editor.ts; `.replaceChildren(` is used for the legend and details dialogs).
