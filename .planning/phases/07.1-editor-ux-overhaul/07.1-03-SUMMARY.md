# Phase 07.1 Plan 03: Raise/Lower split and reporting Summary

Alt is gone from the terrain dispatcher: Raise (H) and Lower (J) are separate tools, Block takes a Raise/Lower direction option, Lock selects on Shift+click, and every height edit reports `heightDeltaM` and `heldVertices` (with a "Held by roads" status when roads absorb the whole edit). Core gained `raiseWindow` and the absolute `snapshotWindow`/`setWindowFromBase` ops for Grid select.
