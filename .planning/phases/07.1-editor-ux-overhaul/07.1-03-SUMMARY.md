# Phase 07.1 Plan 03: Map Editor on the Shared Shell Summary

The map editor now runs entirely on `createShell`: bare index.html, canvas created in code, left rail with flyouts (Select tag editor, Draw road, Move node, Building, Image trace), File/View/Import/Help menus, area picker in the top bar, info bar fields (area, world, tile, cursor, contents, unsaved marker, status), Undo/Redo with a redo-capable snapshot history, Ctrl-based shortcuts, and a New world dialog with inline errors.

## Deviations from Plan
- Tasks 2 and 3 committed together (see above).
- Compile & drive now closes the pre-opened tab if the compile fails, instead of navigating it to the old build (small behaviour improvement, failure reason shows in the info bar).
- Added a canvas `mouseleave` that clears the hover/cursor readout.
- Tag-editor edits rebuild the flyout only on select/deselect/delete/undo, not on each edit, so stepper focus is not lost while stepping.
- Page-local `<style>` in index.html for text inputs, swatches and warnings (no overflow rules).
- Image trace flyout keeps all import state at module level, as planned; Import still targets the CURRENT map (07.1-04 changes that).
