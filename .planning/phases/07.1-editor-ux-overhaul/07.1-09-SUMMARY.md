# Phase 07.1 Plan 09: New popup and fresh-map image import Summary

Image import no longer overlays the open map: the New popup creates a new map (POST new-world, loadArea, trace at offset 0,0, snapshot for Undo, save) and every validation failure is shown inside the popup.

## Tasks
1. planImportWorld + 6 tests: 8a8ee30
2. openNewMapDialog (blank / image), legacy #nw-* / #im-* dialogs and main-canvas import overlay/preview removed: see git log `feat(07.1-09): New popup with fresh-map image import`

## Deviations from Plan
- None of substance. Thumbnail is sampled directly rather than reusing `rebuildImportMask` (which is removed along with the full-canvas overlay).
- Failure after the world was created (load/trace/save) closes the popup and reports in the info bar, as specified.

## Issues
- Not visually or interactively verified (deferred to 07.1-13). Typecheck, biome and 73 map-editor tests pass.
- `footprintWarnings` is kept in image-import.ts (still tested) but is no longer used by the editor.
