<objective>
Implement D-06 for the map editor: one New popup that creates a blank map OR a fresh map from an image, with validation errors inside the popup, and change image import so it can never overlay an existing map (the user's poppmap complaint, D-10).

Purpose: creating a map is currently hard and silent on failure, and import lands on whatever map is open.
Output: pure new-map.ts (+tests) used by both the editor and the dev middleware; precise server errors; the New popup; the Image trace tool reworked into the second stage of a fresh-map import.

Decision recorded here (planner, per orchestrator constraint): importing onto the CURRENT map is DROPPED, not kept. Keeping it would reintroduce the exact overlay D-06 forbids, and the offset X/Y fields only existed for that case. The Offset X / Offset Y steppers are removed (offset is always 0,0 on a fresh map). Metres-per-pixel stays as a linked alternative to Width.
</objective>
