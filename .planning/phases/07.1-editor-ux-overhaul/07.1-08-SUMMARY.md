# Phase 07.1 Plan 08: Terrain editor on the shared shell Summary

The terrain editor now has the D-01 layout: no sidebar, full-bleed canvas, File/Import/View/Help menus, a rail with all eleven tools (Raise H and Lower J separate, no modifier), per-tool flyouts of steppers and selects (Block has a Raise/Lower toggle), view pad camera controls, and an info bar showing area, size, cell, cursor x/z/height, surface, road count, unsaved marker and status. File > New is a popup with Name, Width, Height and a collapsed Advanced cell size, showing inline errors and never overwriting. Save refusals and failures show as info-bar errors and keep the unsaved marker. `[ ]`/arrows step the active tool's main value (Shift = coarse); `[ ]` rotate the stamp when Stamp is active.
