## What changed (editor.ts)

- Selection outline: terrain-hugging LineLoop (0xff66cc, depthTest off, renderOrder 999). Shows the live drag window while selecting, else the stored selection. Rebuilt after selection changes, raise/lower, push/pull, undo/redo. Hidden on area change and when leaving the Grid select tool. Cursor ring hidden for Grid select.
- Flyout: selection readout, "▲ Raise" / "▼ Lower" buttons (via runAction, one undo step each), Step stepper (0.25..5, collapsed slider), "Push/pull" details with Sensitivity stepper (0.005..1 m/px), Clear selection, hint text.
- Ctrl+drag: Ctrl latched at pointer-down only; moves call `pushPullTo(pushPullDelta(...))` (Shift = fine). If the dispatcher refuses (no selection), status shown as an error and the stroke ends.
- Feedback: `giveFeedback` after stroke end and after action results. "Nothing changed: ..." statuses shown as error; otherwise `editFeedback` text shown as ok; the slope-clamp hint is left alone.
- Canvas click with no area loaded: says NO_AREA_MESSAGE (error). The older shorter no-area text in runAction now uses the same message.
- Keys: `[`/`]` (Shift "any") rotate the stamp on Stamp, else adjust the primary value and refresh the flyout/ring; tools with none say so. Esc: cancels a smooth-area drag first, else clears the Grid select selection. All 12 tools in TOOL_KEYS have a rail button and binding (unchanged from 07.1-07).
- Arrow keys: still pan; the shell already skips them while a stepper is focused (07.1-07).
