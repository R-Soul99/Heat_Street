  <what-built>Terrain editor on the shared shell: menubar, tool rail with separate Raise (H) and Lower (J), flyout brush options with steppers, Block Raise/Lower toggle, Lock Shift+click select, Grid select (S) with step buttons, a collapsible step slider and Ctrl+drag push/pull, New popup with inline errors, info bar with cursor height and last change, tooltips toggle.</what-built>
  <how-to-verify>
    Open http://localhost:5173/tools/terrain-editor/index.html in Chrome at about 1280x720.
    1. Layout: no right sidebar, nothing scrolls except a tall flyout; menus File/Area, Import, View, Help; zoom/fit/pan pad bottom-right; Undo/Redo/Clear selection top-right; info bar at the bottom.
    2. Click the canvas before loading anything: the info bar says to load or create an area first.
    3. File > New: try name "Bad Name" (inline error), an existing name (inline "already exists", nothing overwritten), then a valid name 500 x 500 m: a flat area opens.
    4. Raise (H): click once near the camera target: terrain visibly lifts and the info bar shows "last +1 m" or similar. Lower (J): it drops. No modifier keys needed. Zoom out and repeat: is the effect still readable?
    5. Block (B): toggle Raise/Lower in the flyout and click: blocks step up/down.
    6. Grid select (S): drag a rectangle; it stays outlined. Press ▲ three times, then Ctrl+Z once (one step undone). Open the Step section, set 0.5 m, press ▼. Hold Ctrl and drag up/down on the canvas: the selection follows; release; Ctrl+Z undoes the whole drag in one step. Start another Ctrl+drag and press Esc: it snaps back.
    7. Draw a road (R), Lock it (L), then try Raise over it: the info bar says vertices are held by roads and how to unlock. Shift+click the road with the Lock tool: it selects without toggling.
    8. Arrow keys and [ ] change the active tool's main value (radius, or the Grid select step); Shift makes bigger steps; with the Stamp tool [ ] rotate the stamp.
    9. Hover controls: tooltips explain them. Help > Tooltips off; reload: they stay off. Turn them back on.
    10. Ctrl+S saves (info bar shows success); File > Drive here opens the game on this new area (it registered itself on save).
  </how-to-verify>
