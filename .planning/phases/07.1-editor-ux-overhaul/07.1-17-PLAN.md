Root causes already identified by the planner (verify, do not re-diagnose at length):
- dialog.ts only clears `err.textContent` when an action button is clicked, never on edit.
- keys.ts `adjustDirection` matches `e.key` "[" / "]". With Shift held, `e.key` is "{" / "}" on US/UK layouts, so Shift+bracket does nothing. `e.code` stays BracketLeft/BracketRight.
- tooltips.ts `show()` puts the tip below the control, or above it when it would leave the viewport. Bottom-row dock buttons therefore get the tip above them, covering the controls above.
- tests/map-select.test.ts hard-codes the terrain-format list; every new authored terrain map (new-area-1, uat-test, popp-roads) fails it.
