<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Map editor on the shared shell: menus, tool rail (Select V, Draw road R, Move node M, Building B, Eraser E), flyouts with steppers, info bar, Undo/Redo/Clear all, New popup (blank map or Import image with its own Width, fresh map every time), box Select with Roads/Buildings/Objects tickboxes and delete/disable, automatic registration so new maps compile.</what-built>
  <how-to-verify>
    Open http://localhost:5173/tools/map-editor/index.html in Chrome at about 1280x720.
    1. Layout: no right sidebar, nothing scrolls except a tall flyout; menus File/Area, Import, View, Help; zoom/fit/pan pad bottom-right; Undo/Redo/Clear all top-right; the info bar shows area, world size (3 dp), tile, cursor x/y, counts, unsaved marker and status.
    2. Hover controls: tooltips explain each one. Help > Tooltips off, reload, still off; turn back on.
    3. File > New: name "Bad Name" -> inline error; width 12 km -> inline range error; an existing name -> inline "already exists". Then a valid name at 2 x 2 km -> Create: a blank map opens and the info bar says it was created and registered.
    4. Draw road (R): click points, double-click to finish; change Width with the stepper (big +/- buttons, Arrow keys, Shift for bigger steps) and Surface. Dropdowns are only as wide as their content.
    5. Select (V): drag a box over some roads and buildings. Untick Buildings, press Disable ticked roads: they turn grey and dashed. Enable them again. Delete all inside. Ctrl+Z, then Ctrl+Shift+Z (redo) and Ctrl+Y. Objects tickbox is greyed out with an explanatory tip.
    6. Eraser (E): drag across several roads; one Ctrl+Z brings them all back.
    7. Clear all: a confirm dialog appears; confirm; Ctrl+Z restores everything.
    8. Note which map is open (e.g. my-map) and its road count. Import > Import image...: choose the poppmap PNG, Width 1.96 km; the read-out shows the derived height (about 0.941 km) to 3 dp and the thumbnail shows the traced mask. Name it (e.g. "popp-roads") and Create from image. A NEW map opens containing the traced roads at full size; File > Open area on the earlier map shows it unchanged (same road count).
    9. Try importing a very wide, short image (or set Width so height drops below 0.5 km): the popup shows the height-limit error and suggests a larger width.
    10. File > Save & compile on the new map: the info bar reports success or a readable failure (no cli.ts edit needed). If it compiles, File > Compile & drive opens the game on it.
  </how-to-verify>
