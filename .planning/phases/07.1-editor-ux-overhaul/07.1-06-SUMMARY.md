# Phase 07.1 Plan 06: Grid select Summary

DOM-free Grid select in the terrain dispatcher: drag selects a persistent vertex window (no edit, no undo), raiseSelection steps it by selectStepM (0.25-5 m) as one undo entry, and push/pull sets heights as snapshot + delta (clamped to 50 m) with one undo entry or a clean cancel. Road-held vertices never move and are reported via heldVertices.
