# Phase 07.1 Plan 06: Terrain raise/lower and Grid select Summary

Pure terrain-logic work: diagnosed why Raise/Lower "doesn't work", added window height ops to the core brush, and gave the dispatcher a Lower tool, modifier-free Raise/Block, edit feedback, and a Grid select tool with step raise/lower and absolute Ctrl push/pull. No page, runtime, physics, compiler or map data changes.

## Diagnosis finding (verbatim from raise-diagnosis.test.ts)

Finding (07.1-06): the raise op itself works headless. The user-visible failure is explained by C1 (one click lifts ~0.5 m at default strength, effectively invisible at the default camera distance, with only 'Edited.' as feedback), C2 (clicking with no area loaded silently does nothing), C3 (strokes over road-held vertices silently do nothing) and C4 (Alt inverts Raise; Alt on Windows can also steal focus). Fix: separate Raise/Lower tools without modifiers, per-stroke height feedback, an explicit held-by-road message, and a no-area message in the page (07.1-08).

Measured centre lift (C1): a single default click (radius 12 m, strength 0.5, smooth falloff) lifts the highest vertex by **0.4427 m** on a 3 m grid. All five candidates (C1-C5) reproduced on unmodified code; none needed its expectation changed. The diagnosis was committed (7db4154) before any behaviour change. C3 and C4 were updated in Task 3: C3 now expects the held-by-road status, C4 became "Alt is ignored by Raise".

The no-area message (C2) is a page concern and is left for 07.1-08.

## What changed

- `terrain-brush.ts`: `raiseWindow(grid, win, deltaM, rec?, opts?)` and `offsetWindowFrom(grid, win, base, deltaM, rec?, opts?)`, both through `runHeightOp` (road hold, 35 degree limiter, recorder), relax off, windows clipped, non-finite is a no-op.
- `tool-dispatch.ts`:
  - New keys: J lower, A smoothBox, V gridSelect (existing keys kept).
  - `Modifiers` is now `{alt?, ctrl?, shift?}`; Raise/Lower/Block ignore Alt. Block uses `options.blockDirection`. Lock selects on Shift (Alt kept as alias); the regrade hint says "Shift+click".
  - Options: `blockDirection`, `gridStepM` (0.25..5, 0.25 steps), `pushPullMPerPx` (0.005..1).
  - Feedback: `heightChange {maxUpM, maxDownM}` on pointerUp, `heldVertices`, and "Nothing changed: N vertices here belong to a road. Unlock the road with the Lock tool (L) ..." when a dab changed nothing.
  - Grid select: persistent selection (`getGridSelection`, `clearGridSelection`, `gridSelectDragWindow`), `raiseSelection(+/-1)` as one undo entry, Ctrl-down starts push/pull and `pushPullTo(deltaM)` is absolute from a stroke-start snapshot; pointerUp commits one entry. `clearHistory` clears the selection.
