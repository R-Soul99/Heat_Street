# Phase 07.1 Plan 11: Box select, Eraser, disabled roads Summary

**Map editor now has box Select (per-type delete/disable/enable), an Eraser, and grey dashed disabled roads, all undoable as single steps.**

## Task Commits
1. Task 1 select-box helpers + tests: c32d6cd
2. Task 2 editor wiring: cc529e0

## Details
- Select: left-drag (>3 px) draws a dashed box; flyout lists Roads (N), Buildings (M), disabled Objects (0) with tip, Delete ticked, Disable ticked roads, Enable ticked roads (only when disabled roads are inside), Delete all inside, Clear box. Boxed items are highlighted. Esc clears the box; Delete key deletes ticked. Click still single-picks; selected disabled road shows Enable road.
- Eraser (E): size stepper 1..50 m, Roads/Buildings tickboxes, cursor circle; snapshot taken lazily on first hit so misses add no undo entry; [ ] and arrows adjust size.
- Panning: right/middle-drag, pan pad, Ctrl+Arrows (left-drag no longer pans in Select).
