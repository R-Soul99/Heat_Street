## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Editor client -> Vite dev endpoints (/__editor, /__terrain) | Dev-only local server; ids and graphs come from the request | map ids, raw OSM envelopes, terrain sidecar graphs |
