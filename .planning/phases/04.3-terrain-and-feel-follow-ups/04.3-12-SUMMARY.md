## Decisions and caveats

- A first juliette p2p run (120.8 s) was discarded: the user drove mostly cross-country. The kept run follows the roads.
- Point-to-point courses accept checkpoints in any order (`race-state.ts`, order enforced only for circuits), so p2p splits are in hit order.
- juliette circuit (213.05 s): the user reports no corner cutting; a couple of overshoot-and-spin recoveries are inside the time. Sector
  03 to 04 got slower each lap (30.4, 33.6, 37.8 s).
- grid-test circuit (281.467 s): laps 2 and 3 (97.7, 101.2 s) were slower than lap 1 (82.5 s). Kept as an honest human run.
- Circuit totals fell about 30% against the old references, so circuit medals are now much tighter. Revisit if too hard.
- The Circuit Race AI tests still read the frozen legacy fixture and are unchanged.
