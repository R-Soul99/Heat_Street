### `src/physics/vehicle.ts` lift-off reshape (sim, per-tick transform)

**Analog:** same file. Replace only the `liftRaw` expression; keep `lift`, `throttleRef`, `liftHold`, `counterSteerFade`, `rearSfsTarget` wiring.

**Current code to replace** (lines 704-716):
```typescript
const lift = Math.max(0, throttleRef - frame.throttle);
throttleRef += (frame.throttle - throttleRef) * (1 - Math.exp(-DT / LIFT_OFF_REF_TAU));
const liftRaw = clamp(
  t.drive.liftOffOversteer * lift * Math.abs(frame.steer) * lockScale *
    clamp((Math.hypot(lv.x, lv.z) - 8) / 10, 0, 1),
  0, 1,
);
liftHold = Math.max(liftRaw, liftHold * Math.exp(-DT / LIFT_OFF_HOLD_TAU));
const liftBlend = liftHold * counterSteerFade;
```
**Available in scope:** `slipRad` (L695), `lockScale`, `lv`, `clamp`, `lerp`. A smoothstep idiom already exists inline at L697-698: `sm * sm * (3 - 2 * sm)`; copy that form for the progressive shape.

**Where it feeds** (L731-746): `lerp(rearSideFriction, powerOversteerRearSideFriction, Math.max(flickBlend, pivotBlend, powerBlend, liftBlend))`. A cap on `liftRaw` below 1 therefore caps rear looseness from lift alone (D-02). Note `powerBlend` (L718-730) has the same `Math.abs(frame.steer) * lockScale` factor; do not alter it.

**Comment style:** long explanatory `//` blocks citing measured results (see L687-692). Put new constants next to `LIFT_OFF_HOLD_TAU` (L86-94) with doc comments.

### `src/core/terrain-brush.ts` `raiseBlock` / `smoothRegion` (pure op)

**Analog:** `raiseLower` (L284-307) for the call shape; `smoothBrush` (L309-354) for the 1-2-1 kernel.

```typescript
export function raiseLower(grid, params, sign: 1 | -1, rateM = 1, rec?, opts?): BrushResult {
  const p = sanitize(params);
  if (!p || !Number.isFinite(rateM)) return NO_OP;
  const w = circleWindow(grid, p.x, p.z, p.radiusM);
  if (!w) return NO_OP;
  return runHeightOp(grid, w, (x, z, h) => { ... return f > 0 ? h + sign * rateM * p.strength * f : h; }, rec, true, opts);
}
```
For the block: window = integer vertex window `[r0, r0+N] x [c0, c0+N]` (a `CellWindow` `{minRow,minCol,maxRow,maxCol}`), `compute = (x,z,h) => h + sign*stepM`, `relax = false` (relax=true is the soft-brush behaviour; sharp blocks want false, as `smoothBrush`/`flatten` pass), `opts` carries `roadMask`.

**Smoothing kernel** (L332-348): 1-2-1 weights `wgt = (dc===0?2:1)*(dr===0?2:1)`, `h + strength * (sum/16 - h)`, reading `snap(rr,cc)` when inside the window and `grid.heights[...]` outside. For multi-pass, compute passes in a scratch copy then return the final value from `compute`. To skip roads, `compute` must return `h` for masked vertices (the `roadMask` in `HeightOpOptions` L84 only protects the limiter).

**Pipeline facts:** `runHeightOp` (L180-282) is not exported and already does snapshot, slope-limit window expansion, `rec?.beforeHeightsWrite(dirty)`, WR-03 `freezePreexistingSteep`, and `limitSlope`. Return `{ window, slopeClamped }`. No new undo code.

## Shared Patterns

### Layering (enforced by `tests/layering.test.ts`)

### Editor text output (WR-06)
**Source:** `editor.ts` `setStatus` / `log`. All user-facing strings via `textContent`.

### Undo per stroke
**Source:** `tool-dispatch.ts` L346, L389, L493. One `createStrokeRecorder` and one `finish(commit())` per user action; `UNDO_DEPTH` 50.

### Height edits always through `runHeightOp`
**Source:** `terrain-brush.ts` L180-282. Provides slope limit (35 deg), WR-02 road mask, WR-03 preexisting-steep freeze. Never write `grid.heights` directly from new ops.

### Shared geometry for collider and mesh
**Source:** crest flow (`buildCrestGeometry` used by terrain-scene and render). One pure builder feeds both so physics and visuals cannot diverge.

### Fixed cuboids for walls (tunnelling-safe)
**Source:** `buildBuildingCollider` (map-scene.ts L302-316). Thick `ColliderDesc.cuboid`, not trimesh.
