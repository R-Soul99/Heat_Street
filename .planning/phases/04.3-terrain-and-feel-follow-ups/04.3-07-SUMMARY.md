# Phase 04.3 Plan 07: Block and smooth tools Summary

Terrain editor gains a Block raise/lower tool (N x N cells, 0.25-5 m step, Alt lowers), a box Smooth area tool and a Smooth whole map button, each stroke or action one undo step, roads never moved.

## What was built
- Dispatcher: `block` and `smoothBox` tools, `smoothAll()`, options `blockCells`, `blockStepM`, `smoothStrength`, `smoothPasses` (clamped, non-finite ignored). Block dabs are spaced at half a cell and each block steps once per stroke.
- Panel: Block and Smooth area buttons, size/step/strength/passes sliders, metres label (N x N (M m)) refreshed when an area loads, Smooth whole map button (status painted one frame before the run, text via textContent).
- 8 new dispatcher tests (21 total in file); full suite 1786 passing, `npm run check` and `npm run build` clean.

## Deviations from Plan
**1. [Rule 1 - Bug] Shared block edges double-stepped.** Adjacent N x N blocks share edge vertices, so a drag raised seams by 2 steps, contradicting "steps at most once". Fix: a per-stroke stepped-vertex set is OR-ed into the road mask passed to `raiseBlock`, so already-stepped vertices are held. Commit ac464c8 (with test).

**2. Biome formatting/lint** (CRLF working copy, noAssignInExpressions) fixed in the task 2 commit.

None. Block preview cursor remains the ring until plan 10 (as planned).
