# Phase 04.3 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 5.0.0 (node env, Rapier inlined) |
| **Config file** | `vitest.config.ts` (and `vitest.dossier.config.ts` for the feel dossier) |
| **Quick run command** | `npx vitest run tests/<file>.test.ts` |
| **Full suite command** | `npm run check` (typecheck + biome + vitest) |
| **Heavy gate** | `GATE_ENFORCE=1 npx vitest run tests/terrain-gate.test.ts` |
| **Estimated runtime** | quick ~10-30 s; full suite a few minutes |

---

## Sampling Rate

- **After every task commit:** Run the relevant test file(s) from the map below
- **After every plan wave:** Run `npm run check`
- **Before `/gsd-verify-work`:** `npm run check` green, enforced terrain gate green, `npm run feel-dossier` (shipped car) recorded, human sign-off drives done
- **Max feedback latency:** ~30 seconds per task
