<objective>
Build the pure, framework-free simulation core: the absolute-clock fixed-timestep `SimClock`, the per-tick `InputTape`, and the mirrored frame-budget contract - each with Node-runnable tests.

Purpose: This is the phase's load-bearing 120 lines. RESEARCH.md verified by execution that the textbook `acc += frameDelta` accumulator produces 599 ticks at 144fps versus 600 at 60fps with a different world-snapshot hash - a direct SC1 failure - and that a step clamp alone fast-forwards the simulation 5x for twelve seconds after a 60 second alt-tab, a direct SC3 failure. Both fixes live in this one class. `src/core/` stays free of `three`, `document` and `performance.now()` precisely so these criteria are automatable in Node rather than checked by eye.

Output: `src/core/sim-clock.ts`, `src/core/input-tape.ts`, `src/core/frame-budget.ts`, `docs/frame-budget.md`, and three test files.

src/core/sim-clock.ts
  export const DT: number                    // 1 / 60, seconds
  export const MAX_STEPS_PER_FRAME: number   // 5
  export class SimClock {
    tick: number                             // monotonically increasing integer
    droppedTicks: number                     // ticks discarded by rebaseline
    start(nowMs: number): void
    stepsFor(nowMs: number): number          // ABSOLUTE clock, never accumulated
    alpha(nowMs: number): number             // interpolation factor, clamped to [0, 1]
    rebaseline(nowMs: number): void          // moves originMs forward, never rewinds tick
    get simTimeSec(): number                 // === tick * DT. THE run clock.
  }

src/core/input-tape.ts
  export interface InputFrame {
    readonly steer: number      // -1 .. 1
    readonly throttle: number   //  0 .. 1
    readonly brake: number      //  0 .. 1
    readonly handbrake: boolean
  }
  export const NEUTRAL: InputFrame
  export interface InputSource { sampleForTick(tick: number): InputFrame }
  export class RecordingInput implements InputSource {
    constructor(live: InputSource)
    sampleForTick(tick: number): InputFrame
    frames(): readonly InputFrame[]
  }
  export class ReplayInput implements InputSource {
    constructor(frames: readonly InputFrame[])
    sampleForTick(tick: number): InputFrame
  }

    - RecordingInput is idempotent per tick: calling `sampleForTick(7)` twice returns a reference-equal frame and does not append twice
    - RecordingInput fills gaps: if ticks 0,1,2 are sampled and then tick 5 is sampled, indices 3 and 4 hold NEUTRAL and `frames()` has length 6

    - Frame-rate independence (the SC1 case): a tape recorded over 120 ticks, replayed while a SimClock is driven at 30 fps and again at 144 fps, yields the identical ordered list of frames consumed - because consumption is keyed on tick index, not on frame count

  <action>
    Implement `src/core/input-tape.ts`. RESEARCH.md "Pattern 3" is the rationale: if input is sampled once per render frame, a 144 fps run feeds 144 distinct samples per second into 60 ticks while a 30 fps run feeds 30 into the same 60 ticks - the tick sequence is identical but the inputs to it are not, so end states diverge for reasons unrelated to the clock. This file is what makes SC1's phrase "the same recorded input" mean something.

    Define `InputFrame` with readonly `steer`, `throttle`, `brake`, `handbrake`. Phase 2 fills in the real axis semantics; Phase 1 only needs the shape and the latching mechanism to be correct and tested.

    `NEUTRAL` is a module-level `Object.freeze`d `InputFrame`.

    `InputSource` is the single-method interface `sampleForTick(tick: number): InputFrame`.

    `RecordingInput` wraps a live `InputSource`. `sampleForTick(tick)`: if `tick` is already recorded, return the stored frame without re-querying the live source (this idempotence is what lets the loop and the HUD both read a tick safely). Otherwise pad any gap with `NEUTRAL`, query the live source once, store the result at index `tick`, and return it. `frames()` returns a defensive copy typed `readonly InputFrame[]`.

    `ReplayInput` takes `readonly InputFrame[]` and returns `frames[tick] ?? NEUTRAL`, also returning `NEUTRAL` for negative indices.

    Obey the layering rules block: no imports of `three` or Rapier, no DOM identifiers, no wall-clock reads. A browser keyboard/gamepad source is Phase 2's job and lives in `src/input/` outside `src/core/`.
