# Quick 261116-a53: Editor amendments A

All five tasks built. No browser was available, so none of the UI has been seen running.

## What changed

1. **Contextual left pane** (`pane-state.ts`, pure and tested, wired in `editor.ts`). Selecting one placed item
   (ramp, building, tree, bush, hedge, fence) in Select mode swaps the whole left pane for that item's panel:
   "Selected ramp" etc., its controls, hint line, scenery triangle count. Step, Slope limit, Roads, Delete
   scenery in selection and the Start points list are hidden until the selection clears. Place kinds still
   show only their own options (checked, nothing is appended).
2. **Rotation field**. Building, ramp, tree and bush panels get a "Rotation" stepper, 0-359, 1 degree per
   step, wrapping, typed values accepted, with the hint "Left/Right 15°, Shift 1°" beside it. It goes through
   `rotateSelectedScenery` (same pure rotate and refusal rules as the arrow keys); a refused turn snaps the
   field back. Held stepper = one undo step (existing merge window). The Building and Tree/Bush placement
   Rotation controls now step 1 degree (Shift = 15) and wrap, and already accepted typed values.
   `StepperSpec` gained an optional `wrap` flag (tested).
3. **Save as** (File > "Save as...", Ctrl+Shift+S). Dialog asks for a name (default `<area>-copy`), same
   rules as New area (now shared via `save-as.ts`), re-reads the area list right before writing and refuses an
   existing name. Writes a renamed copy (area id, name, graph id) through the existing bin-then-sidecar PUTs,
   leaves the original untouched, then reloads and switches to the new area (camera pose kept; undo history is
   cleared, as with any area load). If you edit during the save it stays on the original and says so.
   Plain Save unchanged. No plugin change needed.
4. **Drive button**. "▶ Drive" at the right end of the top bar in every mode. Runs Drive from (selected else
   default start). With no start point it runs Drive here at the view centre and the info bar says "No start
   point on this map, so driving from the centre of the view." Tooltip names the start and the D key. The
   sidebar "Drive from" button and File entries remain.
5. **Held brush**. Raise, lower, smooth, flatten keep applying while the button is held still: 20 Hz fixed
   tick, long frames clamped to 0.1 s (`hold-brush.ts`, tested). Strength is per second: raise/lower add
   `strength` metres per second at the centre; smooth/flatten blend by the per-tick share of `strength` per
   second. Ticks go through the live stroke recorder, so press + hold + drag is ONE undo step (tested). Held
   ticks pause while the pointer is moving (it applies its own dabs) and resume after 150 ms still. Timer stops
   on pointerup, pointercancel, pointerleave, Esc, dialog open and window blur. Paint, road paint, erase and
   lock are unchanged (tested that held ticks do nothing for them).

## Choices made for you (veto any of these)

- **Start points are not an "item panel".** Start points can only be selected in Place > Start point mode (they
  already have their own list and Drive-from button there). In Select mode a start point is not selectable, so
  I did not add an item panel for it. The Start points list stays a collapsed section of the general Select pane.
- **Rotation sign for ramps** is shown in the same direction as the arrow keys (turning with Left/Right and the
  field agree), so a ramp's displayed number is the negative of its stored heading.
- **Held raise/lower skip the neighbour-relax pass.** `raiseLower` in `src/core/terrain-brush.ts` gained an
  optional `relax` argument (default on, so moving strokes and all other callers are identical). With relax on,
  each 20 Hz tick eroded the bump the previous one built (measured: only ~27% of nominal rate). Held ticks pass
  `relax=false`; the result is the plain falloff-shaped bump.
- **Moving vs held**: a moving stroke still dabs by distance (strength metres per dab); the "same feel" is
  approximate, not exact, since a moving dab is distance-driven and a held tick is time-driven.
- **Save as switches by reloading from disk** (also proves the saved copy loads). Costs the undo history.
- **Top-bar Drive group** is a new bar group with `margin-left:auto` (`.bar-group:has(.drive-btn)` in
  `tools/editor-shell/shell.css`). On a narrow window the bar wraps and it sits at the right of the last row.
- Selected-item panel title is lower-cased kind: "Selected ramp", "Selected hedge".
