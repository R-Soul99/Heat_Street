<objective>
Add a synthetic, code-generated test city ("grid-test") that plugs into the existing map pipeline and loads at runtime like juliette-ga.

Purpose: a controlled handling test bed — staggered block rows (base / 1.25x / 1/1.5x lengths, row phase offsets) and varied road widths produce crossroads, staggered T-junctions, short doglegs and wide-into-narrow corners that the rural OSM map lacks.

Approach (key design decision): do NOT fork the compiler. Generate synthetic Overpass-shaped envelopes (roads + buildings) and write them as the area's raw cache files (`grid-test.raw-osm.json` / `grid-test.raw-buildings.json`) with a bbox identical to the area config. `loadOrFetchArea` then returns them from cache, and the unchanged `buildGraph -> applyFlatElevation -> validateGraph -> heightfield -> buildingBoxes -> collision -> shoulders -> glb` pipeline produces the same artifact set. Routes/medals are authored by a small script against the compiled graph.

Output: generator + pure layout module (with tests), area config + registry entry, compiled grid-test artifacts in public/maps, routes + medals, and an allowlisted `?map=` runtime selector.
</objective>
